# Thumbアセンブリのサンプル

PicoNIXの最小アセンブラで実行できる例です．各 `.s` ファイルは1,024バイト以下です．コードを `/tmp` に保存し，`as ファイル名`，`./a.out` の順に実行します．アセンブルのたびに `/tmp/a.out` は上書きされます．

| ファイル | 内容 |
|---|---|
| `01-exit.s` | `svc #0` による `exit(0)` |
| `02-hello.s` | `adr` と `write` を使う文字列表示 |
| `03-stack.s` | `push` / `pop` によるレジスタ退避・復元（画面出力なし） |
| `04-print-int.s` | `getpid` の戻り値を0〜255の10進ASCIIに変換し `write` で表示 |

## 数値表示の仕組み

`04-print-int.s` では，`r0` に入った0〜255の数値を100と10の繰り返し減算で分解し，`.space 3` で確保したバッファへ `strb` でASCII数字を書き込みます．その後，`write` システムコールで表示します．サンプル内の `print_int` ラベルがサブルーチンの入口です．見やすいラベル名とコメントを使用しています．

この例は32bit整数全域を扱う汎用 `itoa` ではありません．大きな整数や負数を扱うには，より多くのコードが必要です．また，`.space` は実行イメージ内に書き込み用バイトを確保するだけで，特別なメモリ管理は行いません．

**注意**：Cortex-M0+は一般的なユーザメモリ保護を持たないため，不正なアセンブリはOSを停止させる可能性があります．

## ソースコードの書式

ラベルは行頭に，命令や疑似命令はTABで区切って記述しています．`04-print-int.s` も命令をTABでインデントし，処理のまとまりごとに空行とコメントを配置しています．

## プログラムの終了

サンプルのメイン処理はすべて `movs r0, #3`，`movs r1, #0`，`svc #0` による `exit(0)` で終了します．`svc #0` はSVC例外を発生させ，システムコール番号は `r0` に指定します．`bx lr` による暗黙の終了には依存しません．

`04-print-int.s` の `pop {r4,r5,r6,r7,pc}` は**プログラム終了ではなく**，`bl print_int` の呼び出し元へ戻る処理です．
