PicoNIX

A tiny UNIX-like OS for Raspberry Pi Pico / Pico W.

Created by Daisuke Takago.

Source code: GitHub

Hardware demos

  • LED Matrix (8x8)
  • PWM: Servo / Buzzer

To edit this page on PicoNIX:

edit /etc/index.html

Save with Ctrl+S, then exit with Ctrl+Q. Changes are kept in RAM and lost on reboot.
