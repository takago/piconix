PicoNIX

A tiny UNIX-like OS for Raspberry Pi Pico / Pico W.

Created by Daisuke Takago.

Source code: GitHub

Hardware demos

  • LED Matrix (8x8)
  • PWM: Servo / Buzzer

To change this page, copy it to /tmp, edit it, then copy it back to /etc:

dd if=/etc/index.html of=/tmp/index.html
edit /tmp/index.html
dd if=/tmp/index.html of=/etc/index.html

The editor only opens /tmp files. Changes are lost when the device reboots.
