# PicoNIX example material

The exercises in `docs/ja/development/` and `docs/en/development/` provide source-level steps and examples. No source patch is bundled for the uptime exercise: a previous patch no longer applied to the current ABI (system call 40 is `select()`). Follow the instructions and modify a disposable branch instead.
