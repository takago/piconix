# PicoNIX HTTPサーバ

`httpd`はPico WのTCP 80番で動作するユーザプログラムです．カーネルには組み込まれていません．Pico Wの起動スクリプトで自動起動します．

`GET /`で`/etc/index.html`を表示します．スマートフォンのブラウザでは8×8 LEDマトリクスをタッチ編集できます．PWMは画面には表示しませんが，HTTP APIは維持しており`curl`から操作できます．

| HTTP API | 動作 | POST本文 |
|---|---|---|
| `GET /api/fb` | LEDの8バイトを16進16文字で取得 | — |
| `POST /api/fb` | LEDの8バイトを書き込み，表示を有効化 | `3C42A581A599423C` |
| `GET /api/pwm/freq` | PWM周波数（Hz）を取得 | — |
| `POST /api/pwm/freq` | PWM周波数を設定 | `1000`（8〜100000） |
| `GET /api/pwm/a`, `/api/pwm/b` | デューティ比（%）を取得 | — |
| `POST /api/pwm/a`, `/api/pwm/b` | デューティ比を設定 | `50`または`50.0`（0〜100） |

Linux側からの例（`HOST`を実際のPico Wのホスト名またはIPアドレスに置換）：

```sh
curl http://HOST/api/fb
curl -X POST --data-binary '3C42A581A599423C' http://HOST/api/fb
curl -X POST --data-binary '1000' http://HOST/api/pwm/freq
curl -X POST --data-binary '50' http://HOST/api/pwm/a
```

`/etc/index.html`は起動時に初期化されるRAMファイルです．再起動すると編集内容が失われます．`/etc`と`/tmp`は合計11ファイル，各2048バイトまでです．ページを編集する場合は2048バイトの上限を超えないようにしてください．

**制限と安全性：** HTTP/1.0相当の単一接続・逐次処理です．POSTには`Content-Length`が必要で，本文は最大32バイトです．チャンク形式，HTTPS，認証，複数要求の同時処理，keep-aliveには対応しません．TCP 80をインターネットへ公開せず，信頼できる隔離された実験用ネットワーク内でのみ使用してください．PWM出力には危険なアクチュエータを直接接続しないでください．

Telnet（TCP 23）とUDP 2000番のデバイス制御は従来どおりカーネル側に残ります．

### ブラウザでページを開けない場合

URLは `http://<Pico WのIPアドレス>/` を指定してください．HTTPSへの自動切替に注意してください．`curl` では取得できてもブラウザでは開けない場合，ブラウザ固有の大きなHTTPヘッダが原因になることがあります．HTTPサーバは最大2048バイトのリクエストヘッダを受け付け，超過時は HTTP 413 を返します．通常のブラウザでは JavaScript を有効にしてください．

### LEDマトリクスの連続操作

スマートフォンではLEDマトリクスを指でなぞると，通過したマスを連続して点灯・消灯できます．最初に触れたマスが消灯していれば描画，点灯していれば消去になります．同じ操作中はマスを反転せず，一定の点灯状態に揃えます．マウスのドラッグ操作にも対応します．画面は即座に更新し，実機への送信は50 msごとに最大1回だけ試みます．前のHTTP通信が終了するまでは次を開始せず，その間の変更は最新の8バイトへまとめます．指を離した後の最終状態も送信対象になります．全点灯・全消灯も同じ送信制限を使います．通信が失敗した場合の自動再送はしません．

### 現在の表示の自動読み取り

ブラウザは約250 msごとにキャッシュを使わず`GET /api/fb`で実機の表示を読み直し，別のプログラムや`curl`による変更も画面へ反映します．タッチ操作中，未送信の描画があるとき，HTTP通信中は読み取りません．GETとPOSTを同時には送信しません．描画のPOSTは従来どおり最短50 ms間隔で，実際の頻度はPico Wの応答速度によります．

`fbctl test`は500 ms周期で状態を切り替えるため，従来の1秒間隔では同じ状態ばかり取得することがありました．

Web画面の操作ボタンは`Clear`（全消灯）と`All`（全点灯）です．`Read`ボタンは設けず，実機から250 ms周期で自動読み取りします．


### Webページ構成とPWM操作

- `/`（`/index.html`）：PicoNIXの紹介とデモへのリンク．
- `/fbcheck.html`：LEDマトリクス制御画面．50 ms間隔の書き込みと250 ms間隔の自動読み取り．
- `/pwm.html`：サーボ（GP19/PWM1 B）・パッシブブザー（GP18/PWM1 A）の切替テスト画面．

PWMページは，初期状態では出力を開始しません．`Start`で出力し，`Stop`で両チャネルを0%にします．サーボは50 Hz（周期20 ms），パルス幅0.5〜1.5 ms（0.02 ms刻み，デューティ2.5〜7.5%）を指定します．ブザーはデューティ50%固定，周波数100〜5000 Hzを指定します．モード変更時は両チャネルを0%にします．PWM1 A/Bは周波数を共有するため，サーボとブザーは同時には使用できません．外部電源のサーボとPicoのGNDを共通にし，サーボの許容パルス幅を確認してください．

Wi-Fi APへスマートフォンからアクセスできない場合は，モバイルデータ通信やVPNを一時停止し，`http://192.168.4.1/`を直接開いてください．

LED描画領域ではタッチスクロール・文字選択を抑制します．領域外の通常操作は維持します．
