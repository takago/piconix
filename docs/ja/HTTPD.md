# PicoNIX HTTPサーバ

`httpd`はカーネル内のサービスではなく，ユーザ空間で動作するプログラムです．TCP 80番ポートで`GET /`を受け付け，それ以外の要求にはHTTP 404を返します．一度に処理する接続は1つです．

既定のページは`/etc/index.html`です．起動時に作成される書き換え可能なRAMファイルで，`edit /etc/index.html`または`echo ... > /etc/index.html`で編集できます．変更は次の要求から反映されますが，再起動すると失われます．

`/etc`と`/tmp`は最大8個のファイルスロットを共有し，各ファイルの上限は1024バイトです．既定のページも1スロットを使用します．Flashへの永続保存は行いません．Telnet（TCP 23）とUDPデバイス制御（UDP 2000）は引き続きカーネル側のサービスです．

**制限：** HTTP keep-alive，複数クライアントの同時処理，リクエスト本文，MIME種別の自動判定，セキュリティ強化には対応していません．ソケット実装には実験的な部分が残っています．
