# メモリのシンボル表示とタスクスロット

このページは過去の試験実装に関する記述を更新したものです．現在の操作は[メモリ表示](EDIT-MEM.md)と[内部構造](INTERNAL.md)も参照してください．

アプリケーション用RAMは`0x20010000`～`0x20033FFF`の24 KiB×6スロットです．`mem`ではキー`1`～`6`で各スロット，`k`でカーネルRAM，`K`でXIP Flashへ移動できます．ビルドに含まれるアプリとカーネルのシンボルを表示でき，`mem -s sh`や`mem -s kernel`で一覧を確認できます．実行中タスクの配置が変わると，メモリ画面に表示されるシンボル名も変わる場合があります．

旧版の`/proc/syms`，32 KiB×5スロット，カーネルシンボル未対応という記述は現行仕様ではありません．
