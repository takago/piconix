# mem：スロットに応じたシンボルの自動表示

`mem [アドレス]` は従来どおりメモリを表示します．アドレスがタスク用RAMスロットに属するとき，`/proc/tasks` から現在のプログラム名を取得し，既存の `/dev/syms` の該当シンボルをASCII欄の右に表示します．アプリ名の指定は不要です．

- `mem 0x20018000`：指定アドレスから表示．キー `1`～`5` でタスクスロットへ移動．
- `mem -s sh`：従来のシンボル一覧表示．
- タスクが終了・交代したときは，次回の画面更新でシンボルを再取得します．更新は約1秒ごとです．
- 未使用スロット，`/proc/tasks` が取得できない場合，あるいは `/dev/syms` にシンボルがない場合は名前欄を空にし，通常のメモリ表示を継続します．`mem -s` でシンボル情報を明示要求したときは従来どおりエラーメッセージを表示して終了します．
- 現在のFlash内のカタログはアプリのシンボルだけです．カーネルシンボルはまだ表示できません．

**安全上の留意点**：名前とスロットの対応は `/proc/tasks` の読み取り時点のスナップショットです．表示時と実際のタスク配置の間に時間差があり得ます．また，シンボルはアプリの先頭からの相対オフセットで，該当するRAM領域に属する場合のみ表示します．
