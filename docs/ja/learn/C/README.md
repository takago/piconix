# Part C — 上級：UNIXを読んで改造する

ユーザCプログラムを読んでから，起動，スケジューラ，SVC，VFS，ドライバを読み，最後に小さく拡張します．ネットワーク読解は選択章です．

## 章一覧

- [C1　ユーザプログラムから始める](C1.md) — まず変更範囲の小さいCアプリを理解し，カーネルとの境界をつかむ
- [C2　起動，タスク，スケジューラ](C2.md) — ユーザコードが動き始めるまでのカーネル経路をたどる
- [C3　SVC・FD・VFSをコードで追う](C3.md) — write()が標準出力へ到達する経路を追跡する
- [C4　ドライバ：VFSから機器へ](C4.md) — カーネル内部のデバイス境界を理解する
- [C5　選択読解：Pico Wネットワーク](C5.md) **（選択）** — デバイスI/Oとは別に，lwIPとソケットの経路を読む
- [C6　総合演習：小さく安全に拡張する](C6.md) — 観察で作った図を，改造・検証・文書更新へつなげる

**進め方：** C1から順に進めます．C5は省略してもC6へ進めます．

## 学習の前提と次のパート

Part BでFD，TTY，メモリ，SVC，デバイスを観察し，C言語の関数やポインタを理解していることを前提とします．[B5](../B/B5.md)から進めます．
