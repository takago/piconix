# C1　ユーザプログラムから始める

*Part C — 上級：UNIXを読んで改造する*

**この章の到達目標：** まず変更範囲の小さいCアプリを理解し，カーネルとの境界をつかむ．

Part Bでは，アプリから見た入出力とOSの内部の境界を観察しました．Part Cでは最初に，変更の影響が比較的小さい**ユーザプログラム**からソースコードを読みます．いきなりカーネルを書き換えないのは，ビルド，実行，観察，差分確認の基本手順を安全に身に付けるためです．

ソースの`userland/apps/`は各コマンドの実装，`userland/lib/`は共通関数やシステムコールラッパーです．**アプリのコードを読むことと，ライブラリのコードを読むことは別の段階**です．具体的な登録方法やビルド方法は[ユーザCアプリ開発ガイド](../../development/apps/c/PROGRAMMING.md)を正本として確認してください．

## C1.1 実行できるプログラムを読む

ホストPCで`userland/apps/hello.c`と`userland/lib/crt0.c`を読みます．PicoNIXのユーザアプリはCの`main()`を入口にし，システムコールラッパーを使って入出力します．ホストPCのglibcやPico SDKの機能をそのまま呼ぶわけではありません．

## C1.2 新しいプログラムを作る

### まず既存の`hello`を追う

ホストPCで(1) `userland/apps/hello.c`，(2) `userland/lib/crt0.c`，(3) 必要に応じて`userland/lib/syscalls.c`の順に読みます．`main()`で何を表示したいかと，標準出力へバイトを送る仕組みを分けて説明できれば十分です．

| 場所 | 読む理由 |
|---|---|
| `hello.c` | 利用者から見える処理と`main()`を確認する |
| `crt0.c` | 実行開始時と`main()`のつながりを確認する |
| `syscalls.c` | `write()`などがカーネルへ処理を依頼する箇所を探す |

新規コマンドの登録には**アプリ名，プログラムID，ビルド設定**などの整合が必要です．この章の短いコード例だけをコピーしても，追加登録が自動で済むわけではありません．必ず[開発ガイド](../../development/apps/c/PROGRAMMING.md)の現行手順と見比べ，既存ファイルを上書きしない作業ブランチで試します．

例えば次の`greet.c`を**Linux PC側**で`userland/apps/`に作成します．

```c
#include "stdio.h"

int main(int argc, char *argv[]) {
    const char *name = (argc > 1) ? argv[1] : "PicoNIX";
    printf("Hello, %s!\n", name);
    return 0;
}
```

`CMakeLists.txt`のアプリ一覧と`kernel/main.c`での登録が必要です．詳細な追加位置・未使用プログラムIDは[アプリ開発手順](../../development/apps/c/PROGRAMMING.md)で現行ソースを確認してください．

## C1.3 ビルドの結果を実行につなぐ

Linux PCで`./tools/build_sdk.sh -DPICO_BOARD=pico -DCMAKE_BUILD_TYPE=MinSizeRel`などを実行し，出来上がったUF2をPicoへ書き込みます．Pico Wなら`pico_w`を指定します．SDK環境変数や出力場所は[セットアップ](../../setup/SETUP.md)に従ってください．ビルドだけでは実機のプログラムは更新されません．

## C1.4 実習と確認

**読解演習：** `hello.c`で「表示したい文字列」を決めている箇所を見つけます．次に`crt0.c`の起動処理と，`syscalls.c`のカーネル呼出しを探します．**提出する図：** `main()`から標準出力までの経路を，ファイル名つきで3～5段階にまとめます．新しいプログラム追加は，この図を書けた後に行います．

まず既存の`hello`の引数処理を読むだけでも構いません．追加実験をする場合，`greet Alice`の出力を観察します．

1. `main()`の終了後はどうなりますか．
2. Cの`printf()`は直接USBへ書き込んでいますか．
3. Flashの登録とRAMスロットへのロードはいつ起こりますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．

**次に作れる発展課題：** ネットワーク対応のCアプリケーションを作る場合は，[ソケットAPIと実践例](../../development/apps/c/NETWORK-PROGRAMMING.md)にUDP/TCPの完全なソースコード，CMake・イメージ登録，PCとPico Wの動作確認方法があります．
