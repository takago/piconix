## C1.1 実行できるプログラムを読む

ホストPCで`userland/apps/hello.c`と`userland/lib/crt0.c`を読みます．PicoNIXのユーザアプリはCの`main()`を入口にし，システムコールラッパーを使って入出力します．ホストPCのglibcやPico SDKの機能をそのまま呼ぶわけではありません．

## C1.2 新しいプログラムを作る

例えば次の`greet.c`を**Linux PC側**で`userland/apps/`に作成します．

```c
#include "stdio.h"

int main(int argc, char *argv[]) {
    const char *name = (argc > 1) ? argv[1] : "PicoNIX";
    printf("Hello, %s!\n", name);
    return 0;
}
```

`CMakeLists.txt`のアプリ一覧と`kernel/main.c`での登録が必要です．詳細な追加位置・未使用プログラムIDは[アプリ開発手順](../../development/apps/c/PROGRAMMING.md)で現行ソースを確認してください．

## C1.3 ビルドの結果を実行につなぐ

Linux PCで`./tools/build_sdk.sh -DPICO_BOARD=pico -DCMAKE_BUILD_TYPE=MinSizeRel`などを実行し，出来上がったUF2をPicoへ書き込みます．Pico Wなら`pico_w`を指定します．SDK環境変数や出力場所は[セットアップ](../../setup/SETUP.md)に従ってください．ビルドだけでは実機のプログラムは更新されません．

## C1.4 実習と確認

まず既存の`hello`の引数処理を読むだけでも構いません．追加実験をする場合，`greet Alice`の出力を観察します．

1. `main()`の終了後はどうなりますか．
2. Cの`printf()`は直接USBへ書き込んでいますか．
3. Flashの登録とRAMスロットへのロードはいつ起こりますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
