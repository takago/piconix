## C3.1 ユーザからSVCへ

`userland/apps/hello.c` → `userland/lib/syscalls.c`の`write()` → `call()` → `include/piconix_syscall.h` → `kernel/context.S`のSVCハンドラ → `kernel/kernel.c`の`os_svc_dispatch()`の順に読みます．公開APIとABIの番号，SVCと通常の関数呼び出しを混同しないでください．

## C3.2 カーネルからI/O対象へ

`SYS_WRITE`の分岐を探し，FDが指す対象とVFS側の読み書き実装をたどります．端末へ書く場合，ファイルへ書く場合，パイプへ書く場合で**入口は似ていても出口が異なる**ことを確認します．

## C3.3 パイプと待ち合わせ

`userland/apps/shell.c`のパイプライン構築，`pipe()`，`dup2()`，`close()`，EOFを追います．データがないときの待機と，終端で読み手が終了する条件を分けて説明します．初めから全ての例外分岐を読むより，`echo hello | cat`の1回の動作を追うと理解しやすくなります．

## C3.4 読解課題

PicoNIXで`trace run hello`を再実行し，ソースの関数と出力を対応付けます．

1. 呼び出し番号はどこで定義されますか．
2. FDの対象によって分岐するのはどの層ですか．
3. パイプのEOFはどのような条件で起こりますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
