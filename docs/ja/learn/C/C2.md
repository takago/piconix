## C2.1 mainから最初のシェルへ

`kernel/main.c`の`main()`を開き，`os_init()` → `register_image()` → `net_init()` → `os_init_idle()` → `os_start_program(2)` → `os_start()`の順で追います．**登録**と**実行**が別の操作であることを図示してください．

## C2.2 タスクの準備と切替

次に`kernel/kernel.c`の`spawn_in_slot()`，`os_start_program()`，`os_schedule()`，SysTick関連の処理を探します．`kernel/context.S`のPendSVと組み合わせて，スケジューラが次のタスクを選び，CPUの実行文脈を切り替える関係を読みます．

## C2.3 RAMスロットとレジスタ

固定スロット，初期スタック，保存レジスタとPSPを結び付けます．数値を暗記するのではなく，実際の定数は`include/piconix.h`，関数や定義の位置は[関数一覧](../../../FUNCTIONS.md)で調べます．PicoNIXはLinuxの仮想記憶やプロセス隔離を再現するものではありません．

## C2.4 読解課題

**「起動から最初の`sh`へ」**を5〜10個の関数で矢印図にしてください．

1. アプリ登録時と起動時で何が違いますか．
2. SysTickとPendSVが担当する役割は何ですか．
3. アイドルタスクはなぜ必要ですか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
