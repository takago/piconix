# PicoNIX UNIX教科書 — 学習コース総目次

PicoNIXを**使う → 観察する → ソースを読む → 改造する**という流れで学びます．初級（Part A）から上級（Part C）まで，章末の「次へ」で順番に進めます．

**特定の操作・機能を探したいとき：** [目的別索引（やりたいことから探す）](../TASKS.md)．

## この教科書の読み方

各章は，**背景 → 用語と考え方 → 手元で試す → 結果を説明する**という順に読んでください．知らないコマンドが出てきたら，実行例の近くにある操作ガイドへのリンクを参照します．ガイドを読み終えたら，教科書の同じ節へ戻って実習を続けてください．

初級ではまず画面で起こることを理解します．中級の`mem`・`trace`では**操作方法と表示結果の読み方**が必要になります．上級では，観察結果を根拠にソースコードを追います．機材や実行環境で値が変わる部分は，値そのものより意味を説明できることを重視します．

## 共通ルール

- `piconix#`はPicoNIXのプロンプトであり，入力文字ではありません．ホストPCの例は別途「Linux PC側」と明記します．
- USBのみで必修部分を履修できます．Wi-Fiを使う章はPico Wでの**選択実習**です．
- `/tmp`や`/etc`はRAMファイルです．再起動で消えるため，課題の途中で必要なら作り直します．
- 課題は**コマンド → 観察 → 理由 → 自分の言葉での説明**を記録します．PID・時刻・アドレスは毎回同じとは限りません．
- コース本編は自習できるよう必要な説明を含めます．詳しいAPIや配線，制限は[リファレンス](../reference/README.md)と[操作ガイド](../guides/README.md)を参照してください．
- PicoNIXは教育用の簡潔なUNIX風OSであり，LinuxやPOSIXと機能・保護機構が同一ではありません．
