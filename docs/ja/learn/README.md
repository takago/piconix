## 共通ルール

- `piconix#`はPicoNIXのプロンプトであり，入力文字ではありません．ホストPCの例は別途「Linux PC側」と明記します．
- USBのみで必修部分を履修できます．Wi-Fiを使う章はPico Wでの**選択実習**です．
- `/tmp`や`/etc`はRAMファイルです．再起動で消えるため，課題の途中で必要なら作り直します．
- 課題は**コマンド → 観察 → 理由 → 自分の言葉での説明**を記録します．PID・時刻・アドレスは毎回同じとは限りません．
- コース本編は自習できるよう必要な説明を含めます．詳しいAPIや配線，制限は[リファレンス](../reference/README.md)と[操作ガイド](../guides/README.md)を参照してください．
- PicoNIXは教育用の簡潔なUNIX風OSであり，LinuxやPOSIXと機能・保護機構が同一ではありません．
