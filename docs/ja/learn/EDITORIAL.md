# 教科書の編集方針

**資料区分：教材制作者向けメモ** ｜ [教科書総目次](README.md)

- **学習の筋道：** Part A「操作」，Part B「観察」，Part C「コード読解・改造」．各章には前提・説明・実習・確認問題を含め，本文だけで一通り進めるようにします．
- **番号：** `A1`は章，`A1.1`は節です．番号は**教科書にだけ**付けます．既存の技術資料の章番号は技術文書内の見出しとして扱い，教科書の番号ではありません．
- **ナビゲーション：** 教科書の章末だけに「前へ／Part目次へ／次へ」を配置します．選択章は主経路から分岐させ，対応機材のない学生の学習を止めません．
- **リンク表現：** 詳細説明へのリンクには「補助教材」「リファレンス」「開発ガイド」を明記します．戻る先は前の教科書ページです．
- **実習の安全：** `piconix#`はPicoNIX側，`sh`ブロックはLinux PC側．外部回路とPico Wは前提機材と安全上の注意を明示します．
- **技術的根拠：** コマンドとAPIの説明は，その回に提供された最新版ソースを確認します．テスト未実施の改造例はその旨を明記します．日英は章節・リンク・注意書きの単位で対応させます．
- **正本の分担：** 体系的な学習の順序・基本実習・確認課題は番号付き教科書を正本とします．コマンドの細部は操作ガイド，APIの仕様と制限はリファレンス，実装手順は開発ガイド，実際の動作はソースコードで確認します．
- **重複の廃止：** 古い学習順路・同一内容の実習ページは，内容を教科書へ移した後で削除します．別の正本を増やさず，旧版はGit履歴で確認します．
- **文書の保守：** 改訂時はリンク切れと日英対訳を検査し，履歴文書を現行仕様と混同しません．
