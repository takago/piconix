# Part A — 初級：UNIXを使う

**資料区分：学習コース目次** ｜ [教科書総目次](../README.md) ｜ [English](../../../en/learn/A/README.md)

シェルから始め，ファイル，パイプ，プロセスを操作してUNIXの「外側」を理解します．通常のPicoだけで進められます．

## 章一覧

- [A1　PicoNIXとUNIXの入口](A1.md) — 起動済みのPicoNIXを操作し，コマンドとOSの役割を区別する
- [A2　ファイルからストリームへ](A2.md) — 保存する入出力と，その場で流す入出力の違いをつかむ
- [A3　プログラムとプロセス](A3.md) — 登録されているプログラムと，実際に動いているプロセスを区別する
- [A4　初級のまとめ：小さなUNIX実験](A4.md) — これまでの知識を一つの手順にまとめ，中級へ渡す

**進め方：** A1から順番に読み，各章の「実習と確認」に答えてください．

## 学習の前提と次のパート

事前知識は不要です．ビルド・端末接続は[セットアップ](../../setup/SETUP.md)を利用してください．最後は[B1](../B/B1.md)へ進みます．
