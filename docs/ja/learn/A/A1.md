# A1　PicoNIXとUNIXの入口

*Part A — 初級：UNIXを使う*

**この章の到達目標：** 起動済みのPicoNIXを操作し，コマンドとOSの役割を区別する．

**この章を読む前に：** PicoNIXを操作するために必要なのは，まず「端末に文字を入力し，返された結果を読む」ことだけです．この段階ではC言語や電子回路の知識は必要ありません．まだ実機に接続していない場合は，[セットアップ手順](../../setup/SETUP.md)から始めます．

UNIXを学ぶとき，最初からカーネルの内部を暗記する必要はありません．まず，**人が入力するコマンド**，**コマンドを解釈するシェル**，**実行や資源管理を担当するOS**を分けて考えます．例えば`ls /tmp`は「シェルに文字列を入力した」操作ですが，名前の一覧を取得する処理にはカーネルの機能が関わります．この区別を以後の章で繰り返し確かめます．

## A1.1 UNIXを「使う」とは

UNIXでは，**シェル**が利用者のコマンドを受け取り，OSがプログラムの実行や入出力を支えます．まず「コマンドを入力する人」「実行するプログラム」「資源を管理するカーネル」を別々の役割として考えます．PicoNIXは小さなUNIX風OSですが，この基本構造を実機で観察できます．

## A1.2 端末に接続する

### 画面を読み違えないために

- `piconix#`は入力待ちを示す表示であり，コマンドの一部ではありません．端末を接続している**Linux PC側**のシェルとは区別してください．
- `pwd`が返すのは「現在の作業ディレクトリ」，`ls /tmp`が返すのは「指定した場所の一覧」です．表示が似ていても問いが違います．
- `/bin`の名前は実行できるプログラム，`/proc`の名前はOSがその時点で提供する情報です．同じ`ls`で見えてもディスク上の同種のファイルだとは限りません．

**小さな確認実験：** `help cat`を実行してから`cat /proc/uptime`を試します．前者はコマンドの使い方，後者は起動後の状態を調べる操作です．失敗した場合は，まず`help cat`の説明と入力した綴りを照合してください．

[セットアップ](../../setup/SETUP.md)に沿ってPico/Pico Wへ書き込み，USBの端末を開いてください．`piconix#`は**PicoNIXのプロンプト**であり，入力する文字には含めません．以下はPicoNIX側で実行します．

```text
piconix# help
piconix# pwd
piconix# ls /
```

`help`はコマンドの調べ方，`pwd`は現在位置，`ls`はディレクトリの一覧です．最初の時点ではコマンドを暗記する必要はありません．

## A1.3 ディレクトリを歩く

```text
piconix# ls /bin
piconix# ls /tmp
piconix# ls /dev
piconix# ls /proc
```

`/bin`は登録されたプログラム，`/tmp`は書き込み可能なRAMファイル，`/dev`はデバイスの入口，`/proc`は実行中の状態を示します．**同じファイル風の名前でも実体が異なる**ことに注目してください．

**追加観察：** `pwd`の結果と`ls /`の一覧を比べます．`pwd`は現在のディレクトリを示し，`ls`は指定した場所に存在する項目を表示します．`ls /dev`と`ls /proc`はどちらも名前を返しますが，前者は機器への操作口，後者はOSの現在の状態です．Linuxで知っているコマンドがすべてPicoNIXでも使えるわけではありません．コマンドの書式は`help`や`help コマンド名`で確認してください．

## A1.4 実習と確認

**手順を追う実習：** (1) `help`でコマンド一覧を見る．(2) `pwd`の結果を記録する．(3) `ls /bin`と`ls /proc`を比較する．(4) 同じ`ls`コマンドなのに何が違うか説明する．答えのヒントは「項目名がどこから来るか」です．**つまずいたら：** まずプロンプトがPicoNIX側か確認し，`help ls`で書式を調べます．

`help cat`で未知のコマンドを調べ，`ls /bin`から見つけた名前と比較します．次の問いに自分の言葉で答えてください．

1. シェルとカーネルは何を分担しますか．
2. `/bin`と`/proc`が異なるのはなぜですか．
3. `piconix#`の行とLinux PC側の端末をどう区別しますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
