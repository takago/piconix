# A2　ファイルからストリームへ

*Part A — 初級：UNIXを使う*

**この章の到達目標：** 保存する入出力と，その場で流す入出力の違いをつかむ．

A1では，`ls`で名前を調べました．この章ではその名前を使って**データを保存する**ことと，プログラム同士で**データを受け渡す**ことを学びます．ここがUNIXの重要な転換点です．コマンドが互いの内部を知らなくても，入出力をつなげば新しい処理を作れます．

初めて出てくる記号はシェルが解釈します．`>`は出力をファイルへ向け，`>>`は末尾へ追記し，`|`は右隣のプログラムへ出力を渡します．記号自体を`echo`や`cat`が解釈しているわけではありません．詳しい制限と内部で使うFDについては[パイプと標準入出力の操作ガイド](../../guides/PIPE.md)を参照してください．

## A2.1 ファイルに書いて読み戻す

次の操作をPicoNIXで実行します．

```text
piconix# echo hello > /tmp/hello.txt
piconix# cat /tmp/hello.txt
piconix# cp /tmp/hello.txt /tmp/copy.txt
piconix# cat /tmp/copy.txt
```

`echo`は文字列を出力し，`>`はその出力をファイルへ向けます．`cat`は内容を読み，`cp`はコピーを作ります．PicoNIXの`/tmp`はRAM上にあるため，再起動後に内容は残りません．

`cp SRC DST`は`/tmp`と`/etc`直下のRAMファイルをコピーします．コピー先が存在すれば上書きし，再起動するとコピーは消えます．途中で書込みに失敗した場合，コピー先が不完全になる可能性があります．

```text
piconix# cat -n /tmp/hello.txt
piconix# echo >> /tmp/hello.txt
piconix# cat -n /tmp/hello.txt
```

`cat -n`は**空行にも**表示上の行番号を付けますが，ファイルの内容そのものは変更しません．`>>`は末尾への追記です．

## A2.2 標準入出力

### 保存と通信を図にする

```text
echo hello  >  /tmp/hello.txt      文字列 → RAM上のファイル
echo hello  |  cat                 文字列 → パイプ → cat → 端末
```

`>`で作ったファイルはコマンドの終了後にも残ります（再起動まで）．パイプのデータはその場で読み手に渡され，`/tmp`へ自動保存されません．ここでいう**標準入力**は，プログラムが特別な指定なしにデータを受け取る入口，**標準出力**は通常の出力先を表します．これらの実体は次のPart Bで「ファイルディスクリプタ」として調べます．

**予測してから実行：** `echo hello | grep zzz`では，`grep`が指定文字列を含む行を選ぶため，通常は行を表示しません．`grep hello`と比べ，「どのプログラムが何を決めたか」を説明してください．PicoNIXの`grep`は正規表現ではなく簡単な文字列検索です．

`cat`は引数としてパスを受け取ることも，**標準入力**からデータを受け取ることもできます．コマンドの表示先は通常**標準出力**です．プログラム側が端末の名前を意識しなくても，シェルが入出力先を切り替えられます．

```text
piconix# echo hello
piconix# echo hello | cat
piconix# echo hello | cat -n
```

## A2.3 パイプでつなぐ

```text
piconix# echo hello | grep hello | cat
```

`|`は左のコマンドの標準出力を右のコマンドの標準入力へつなぎます．**ファイルに保存してから読む操作ではありません**．PicoNIXでは最大3コマンドのパイプラインを扱えます．Linuxのシェルと同じ引用や複雑なリダイレクトをすべて提供するわけではありません．

もう一つ試すには，`echo hello | cat -n`と`echo hello | grep hello | cat`を実行します．標準入力（FD 0），標準出力（FD 1），標準エラー出力（FD 2）を区別してください．パイプは一時的なバイト列の流れで，RAMファイルとして自動保存されません．短時間で終わるコマンドは，後から`lsof`を実行してもFDが残っていない場合があります．

## A2.4 実習と確認

**手順を追う実習：** (1) `echo abc > /tmp/a.txt`で保存する．(2) `cat /tmp/a.txt`で読み戻す．(3) `echo abc | cat`でファイルを経由せず出力する．(4) `ls /tmp`で残っているファイルを確かめる．**確認すべき結果：** 画面に同じ`abc`が出ても，前者にだけ保存先があり，後者のパイプは一時的な通信路です．

`echo hello > /tmp/hello.txt`と`echo hello | cat`を比較してください．

1. どちらの結果は後から`cat /tmp/hello.txt`で確認できますか．
2. `cat`に入力先を教えるのは誰でしょうか．
3. パイプの右側を`grep hello`に替えると何が変わりますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
