# B4　traceで見るシステムコール

*Part B — 中級：UNIXを観察する*

**この章の到達目標：** ユーザプログラムからカーネルへ入る経路を観察する．

A3の`ps`は「**いま，どのタスクがあるか**」を表示しました．一方で「**そのタスクがどんなシステムコールを呼んだか**」を時間順に確かめるには`trace`を使います．両者は観察の対象が違います．`hello`を実行して文字が出るまでの間に，ユーザコードがカーネルへ処理を依頼することを確認しましょう．

**用語：** システムコールはアプリがOSへ処理を要求する入口，SVCはRP2040のCPUでその境界を通るために使う例外，PIDはタスク識別番号です．詳細なコマンド操作と表示列の意味は[操作ガイド：trace](../../guides/TRACE.md)，APIの引数は[システムコールリファレンス](../../reference/SYSCALLS.md)にあります．

## B4.1 観察の仮説を立てる

`hello`が文字列を表示するとき，アプリがUSB周辺回路へ直接書き込む必要はありません．`write()`などのインターフェースを介してカーネルへ依頼します．呼び出しと復帰を`trace`で調べます．

## B4.2 traceを実行する

### まず`trace run`を読めるようになる

`trace run hello`は`hello`を**新しく起動**し，終了を待ち，そのプロセスのイベントを表示します．先にPIDを調べる必要はありません．実行中の別タスクをあとから追いかける操作ではない点に注意してください．

| 表示項目 | 読み取り方 |
|---|---|
| Time | 記録時刻．他の実行と値が一致する必要はない |
| PID / Command | どのプロセスの記録か |
| `ENTER` | システムコールへ入ったイベント |
| `EXIT` | システムコールから戻ったイベント |
| Call | `write`など，実行された呼び出しの名前 |
| Ret / Data | 戻り値や，取得可能な範囲のデータ（全文とは限らない） |
| `SWITCH` | 実行するタスクの切替に関するイベント |

**読み方の手順：** (1) `hello`の通常の表示を確認し，(2) 同じ実行の`ENTER write`と`EXIT write`の対応を探し，(3) 戻り値を見ます．`write()`が複数回現れる場合は，文字列と改行を別々に書いた可能性などを考えますが，記録だけで内部実装を決めつけずC3でソースと照合します．

`trace show`は以前の記録を表示し，`trace follow`は新しいイベントを表示しますが，**どちらも対象コマンドを起動しません**．最初の実習では`run`を使えば十分です．記録は有限のリングバッファで，長い処理では古いイベントが上書きされることがあります．

```text
piconix# trace run hello
piconix# cat /proc/uptime
piconix# ps
```

`trace run hello`ではSVCに入るときと戻るときなどの記録を確認します．表示されるPID，時刻，イベントの並びは実行時に変わります．`write()`を見つけたら，出力文字列と関係付けてください．

次に`trace run ls`を試し，`trace run hello`と比較します．`ENTER`と`EXIT`はシステムコールの入口と復帰を示し，`SWITCH`はタスク切替を示します．記録はリングバッファなので古いイベントが失われることがあります．`lsof PID`で実行中のタスクのFDを調べる場合は，事前に`ps`でPIDを確認してください．`/proc/uptime`や`/proc/tasks`の値も実行時に変化します．

## B4.3 観察から仕組みへ

Cライブラリで呼び出したAPIが，SVC例外を通してカーネルのシステムコールディスパッチへ到達します．中級では関数の内部実装をまだ全部読む必要はありません．**利用者コード／ABI／カーネル**の境界を図にすることが目標です．

## B4.4 実習と確認

**手順を追う実習：** (1) `trace run hello`で普通の出力とトレースを確認する．(2) `ENTER`と`EXIT`が対応する`write`を探す．(3) 同じことを`trace run ls`で試す．(4) システムコール名の違いを比べる．**記録の仕方：** 時刻・PID・Call・Retの4項目を抜き出し，「どの操作をOSへ頼んだか」を1行ずつ説明します．数値は毎回同一でなくても構いません．

トレースから，どのプログラムが何のシステムコールを行ったか記録します．

1. `ps`と`trace`の違いは何ですか．
2. システムコールと通常のC関数呼出しの違いは何ですか．
3. `write()`の結果はどのように標準出力と関係しますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
