# B3　Flash・RAMとタスク

*Part B — 中級：UNIXを観察する*

**この章の到達目標：** プログラムの保存場所と実行場所の違いを観察する．

これまで`ps`でタスクを観察しましたが，タスクの命令やデータが**どのメモリに置かれているか**は分かりません．RP2040にはFlashとSRAMがあり，PicoNIXではカーネル命令をFlashからXIP実行し，ユーザプログラムをSRAMの固定スロットへコピーして動かします．この「保存場所」と「実行場所」の違いを，実機で確かめます．

**用語：** XIPはFlash上の命令をその場で実行する方式，PICは配置先が変わっても使えるように作られた位置独立コード，シンボルは関数名などとアドレスを対応付ける手掛かりです．初心者はアドレスの数字を暗記する必要はなく，`0x100...`と`0x200...`が別の領域であることから始めます．[メモリ配置図](../../reference/MEMORY-LAYOUT.md)を開いておくと観察しやすくなります．

## B3.1 Flashに置くもの

PicoNIXのカーネル命令はFlashからXIP実行されます．一方，ユーザプログラムはFlash上にPICイメージとして格納され，起動すると選ばれた**RAMの固定スロット**へコピーされます．「どこに保存するか」と「どこで動くか」を区別してください．

## B3.2 メモリを観察する

### `mem`の表示を理解する

ここで使う`mem`は**メモリを読み取って表示するコマンド**です．メモリを書き換えるエディタではありません．詳しい操作キーは必ず[操作ガイド：mem](../../guides/MEM.md)で確認してください．

| 操作 | 読み取れること |
|---|---|
| `mem -s` | シンボルの情報源を一覧にする（**全画面表示ではない**） |
| `mem -s kernel` / `mem -s sh` | カーネル／シェルに付いたシンボル名を調べる |
| `mem`（対話画面） | アドレスごとの16進バイトを観察する |
| `1`～`6`（対話画面内） | ユーザ用の各RAMスロットへ移動する |
| `k` / `K`（対話画面内） | カーネルRAM／XIP Flashへ移動する |
| `q`（対話画面内） | `mem`を終了してシェルへ戻る |

`mem -s sh`でシンボルが表示されても，その時点で`sh`のすべての命令が必ず画面に現れるわけではありません．シンボル一覧と生の16進数表示は別の情報です．実行中のRAMは変わり得るため，特定のバイトが変化しただけで原因を断定しないでください．

```text
piconix# ps
piconix# mem -s
piconix# mem -s kernel
piconix# mem -s sh
```

シンボルの一覧と表示位置から，カーネル・ユーザアプリの領域を区別します．アドレスや占有量はビルドによって異なります．**この段階ではメモリを書き換えません**．

**追加観察（読み取り専用）：** `mem`を起動したら，`1`〜`6`で各ユーザスロット，`k`でカーネルRAM，`K`でXIP Flashを表示し，`q`で終了します．空スロットにプログラムが置かれているとは限りません．実行中のデータは観察する時点で変化し得ます．16進数アドレスは[SRAM配置の仕様](../../reference/MEMORY-LAYOUT.md)と照合してください．

## B3.3 なぜ固定スロットなのか

RP2040のSRAMは限られています．PicoNIXはスロットの大きさと個数を固定し，複雑な仮想記憶を採用しません．これにより配置を理解しやすい一方，実行できるプロセス数やプログラムの大きさに制限があります．

## B3.4 実習と確認

**手順を追う実習：** (1) `ps`で実行中のタスクを確認する．(2) `mem -s`でシンボル情報源を見る．(3) `mem`を開き，`1`～`6`，`k`，`K`を順に試す．(4) `q`で終了し，メモリ配置図と見比べる．**記録の仕方：** 観察した領域（ユーザRAM／カーネルRAM／Flash），画面下部のタスク表示，変化したバイトの有無を分けて書きます．変化した理由を決めつけず，「何を追加観察すればよいか」を考えます．

[メモリ配置](../../reference/MEMORY-LAYOUT.md)の図表と`mem`の表示を対応させます．

1. カーネルとユーザプログラムの命令は同じ場所から実行されますか．
2. PICが必要な理由を固定スロットと関連付けて説明できますか．
3. `ps`と`mem`は何を別々に見ていますか．

学習の記録：**実行したこと／結果／その理由**を1〜3文ずつ書いてください．
