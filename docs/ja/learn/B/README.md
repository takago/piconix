# Part B — 中級：UNIXを観察する

操作した結果をFD，TTY，メモリ，システムコール，デバイスという「内側」から説明します．ネットワークのみPico Wの選択章です．

## 章一覧

- [B1　FDとVFS：名前をI/Oへつなぐ](B1.md) — ファイル・端末・パイプを同じ操作で扱える理由を説明する
- [B2　TTY：入力と画面の境界](B2.md) — 端末の入力設定と，アプリケーションの描画を区別する
- [B3　Flash・RAMとタスク](B3.md) — プログラムの保存場所と実行場所の違いを観察する
- [B4　traceで見るシステムコール](B4.md) — ユーザプログラムからカーネルへ入る経路を観察する
- [B5　デバイスはファイルに見える](B5.md) — デバイスI/Oを通常ファイルと比較し，OSの抽象化を説明する
- [B6　選択実習：Pico Wのネットワーク](B6.md) **（選択）** — デバイスの次に，通信をソケットとユーザプロセスとして観察する

**進め方：** 必修章を順に進めます．B6は省略してもC1へ進めます．

## 学習の前提と次のパート
