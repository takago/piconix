# Part B — 中級：UNIXを観察する

操作した結果をFD，TTY，メモリ，システムコール，デバイスという「内側」から説明します．ネットワークのみPico Wの選択章です．

## このパートの学習ストーリー

Part Aで使ったコマンドを，今度は**OSの観察対象**として扱います．B1でFDとVFS，B2でTTY，B3でメモリ上の実行，B4でシステムコールの記録，B5でデバイスとの境界を確認します．B6はPico Wで通信まで観察したい場合の選択章です．

**初めて使う観察ツール：** `mem`と`trace`は普通のファイル操作コマンドではありません．B3を始める前に[操作ガイド：mem](../../guides/MEM.md)，B4を始める前に[操作ガイド：trace](../../guides/TRACE.md)の基本操作を確認してください．本文にも読み方を示します．

**このパートが終わったら：** `echo hello | cat`が動く理由を，FD・パイプ・システムコールという言葉を使って説明できることを目指します．

- [B5　デバイスはファイルに見える](B5.md) — デバイスI/Oを通常ファイルと比較し，OSの抽象化を説明する
