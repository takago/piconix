# mem — 読み取り専用メモリビューア

`mem`はRAMやXIP Flashを参照するためのコマンドです．**メモリの編集・書き換えはできません**．

`mem` または `mem 0x20018000` のように起動します．
既存の `/dev/mem` から約1秒間隔で読み取り，変化したバイトを反転表示します．
読み取り可能な範囲は `/dev/mem` が許可するXIP Flash 0x10000000〜0x101fffff と SRAM 0x20000000〜0x2003ffff です．
内容は他タスクによって同時に変更されるため，一貫したスナップショットとは限りません．

`mem -s`でシンボル情報源の一覧を表示でき，`mem -s sh`や`mem -s kernel`でアプリ・カーネルのシンボル一覧を表示できます．通常のメモリ表示中も，現在のアドレスに対応するシンボルを表示します．

画面の高さを取得し，1行16バイトで最大36行（576バイト）まで表示します．見出し3行と操作案内3行を確保するため，24行端末では18行（288バイト）を表示します．端末から画面サイズの応答がない場合は80×24として扱います．画面の大きさは起動時に決まり，実行中のサイズ変更には追従しません．

操作キーは次のとおりです．

| キー | 動作 |
|---|---|
| `↑` / `↓` | 16バイトずつ移動 |
| `PgUp` / `PgDn` | 表示中の1ページ分（16バイト×表示行数）移動 |
| `SPACE` | 更新の一時停止・再開 |
| `1`～`6` | 対応する24 KiBタスクスロットへ移動 |
| `k` / `K` | カーネルRAM / XIP Flashへ移動 |
| `g` | 16進アドレスを入力してジャンプ |
| `q` | 終了 |

シンボルデータが利用できなくてもメモリ表示は続行します．


## 試してみよう：RAMとFlashを見比べる

1. `mem`を起動し，表示中のアドレスと，時間とともに反転表示されるバイトを観察します．反転表示は読み取った値の変化を示し，書き換え操作ではありません．
2. `1`〜`6`でユーザタスク用RAMスロットへ移動します．画面下部のタスク名表示と合わせて，どのスロットが使用されているか確認します．
3. `k`でカーネルRAM，`K`でXIP Flashへ移動し，アドレス帯と表示内容を比較します．カーネルのコードは主にFlashからXIP実行されます．
4. `q`で終了した後，`mem -s`や`mem -s kernel`でシンボル情報を確認します．シンボルはアドレスの読み取りを補助するもので，すべてのアドレスに名前が付いているわけではありません．

**注意：** 実行中のRAMは常に変化し得ます．表示は同一時点の完全なスナップショットではありません．`mem`からメモリを書き換えることはできません．
