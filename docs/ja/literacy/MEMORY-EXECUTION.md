# メモリとプログラムの実行

[学習ガイド](LEARNING-PATH.md) | [English](../../en/literacy/MEMORY-EXECUTION.md) | [メモリ配置仕様](../reference/MEMORY-LAYOUT.md)

## 目的と準備

**目的：** Flash（XIP），RAM，タスクスロット，スタック，PICイメージの関係を説明することです．前提はアドレスと16進数の基礎です．USB接続だけで行えます．**メモリは観察にとどめ，アドレスへの書き込みはしません．**

## 実習

```text
piconix# ps
piconix# mem -s
piconix# mem
```

全画面`mem`では`1`〜`6`でユーザスロット，`k`でカーネルRAM，`K`でXIP Flashへ移動し，`q`で終了します．現在のスロットでタスクが動いていなければ，プログラムがあるとは限りません．表示中にバイトが変わっても異常ではありません．

## 観察・考察

- なぜカーネルのコードは主にFlashから直接実行されるのでしょうか．
- ユーザプログラムのコードをRAMの異なるスロットで動かすためにPICが役立つのはなぜですか．
- `ps`のタスクと`mem`のスロットをどのように対応付けられますか．
