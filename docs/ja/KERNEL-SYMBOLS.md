# `mem` のカーネルシンボル表示（試験実装）

`mem -s kernel` はカーネルELFの関数・静的関数・グローバル変数などのシンボルを絶対アドレスで表示します．通常の `mem` は，表示中のアドレス範囲に対応するカーネルおよびタスクスロットのシンボルを自動的に選び，`SYMBOL: kernel, sh` のように表示します．16バイトの行に複数のシンボルがある場合はカンマで区切ります．

## 仕組み

- カーネルシンボル用にFlash内に32KiBの固定長領域を確保します．使用するのは先頭4バイトの長さと，その直後に記録したシンボル情報だけです．
- `tools/build_sdk.sh` は，通常リンク後のELFを `nm` で調べてシンボル情報を生成し，再リンクしたあと，最終ELFのシンボルアドレスが同一であることを検証します．
- ユーザランドは従来どおりスロット相対オフセット，カーネルは絶対アドレスです．`/proc/sym/kernel` と `/proc/sym/userland/<アプリ名>` から個別に参照できます．従来の統合ファイルは廃止しました．
- シンボル情報がない場合や取得できない場合，通常のメモリダンプは継続します．`mem -s kernel` ではメッセージを表示して終了します．

## 確認

```
mem -s kernel
mem 0x20000000
mem 0x10000000
mem -s sh
```

**注意：** 初期の試験実装時点では，Cortex-M0+向けの完全ビルドと実機動作が未検証でした．これは当時の検証状況を記録したもので，現行リリースの検証状況を示すものではありません．書き込み前にはビルドスクリプトのリンク後検証が通ることを確認してください．
