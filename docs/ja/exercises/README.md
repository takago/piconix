# PicoNIX 演習資料

操作ガイドは使い方と実行例，リファレンスは現行仕様，開発ガイドは読解と実装手順を説明します．この資料では，読者が自分で確認・比較・考察する課題を集めています．

- [カーネルトレース演習](TRACE.md)：システムコール・関数トレース・非同期処理を観察する．
- [カーネル読解演習](KERNEL-READING.md)：各段階の確認問題と総合課題．

## RAMとFlashを比較する（`mem`）

[メモリビューアの操作ガイド](../guides/MEM.md)に従って，次の観察を行ってください．

1. `mem` を起動し，アドレスと変化したバイトの反転表示を確認します．表示が変わった理由を考えてください．
2. `1`～`6` でタスクスロットを切り替え，画面のタスク名と対応付けてください．
3. `k` と `K` でカーネルRAMとXIP Flashを比較し，両者の用途の違いを説明してください．
4. `mem -s kernel` を実行し，シンボル名がアドレスの理解にどう役立つか考えてください．

**注意：** RAMは実行中に変化します．`mem` の表示は完全な同時刻のスナップショットではありません．

## Linuxとの違いを観察する

PicoNIXのシェルで次のコマンドを実行します．

```sh
ps
cat /proc/memory
ls /bin
ls /dev
ls /proc
cat /proc/ramfiles
echo hello | cat -n
```

`ps`のタスク数を6個のスロットと比較し，通常のファイルと仮想ファイルの違いを観察してください．さらに，ユーザプログラムからの`read()`や`write()`がシステムコールを経由してVFSへ届く処理をソースコードで追ってみてください．Pico Wでは`ping`と`tcpdump`も試せますが，結果はネットワーク接続状態によります．

**学習のポイント：** PicoNIXはUNIXの概念を小さなコードで再現する教材です．同じ名前のコマンドやAPIがあっても，Linux・POSIXと同じ機能をすべて持つとは限りません．

## ネットワーク観察

Pico Wのネットワーク表示を操作ガイドに従って確認してから，次の問いを考えてください．

1. `lo0`とWi-FiのIPはどう違いますか．`inet`に表示されているのはPico W側とPC側のどちらのアドレスですか．（[IP.md](../reference/network/IP.md)）
2. `RX`の向きは誰の視点ですか．TCPの`SYN`と`ACK`はどんな役割ですか．UDPとICMPにTCPのポート・フラグがないのはなぜですか．（[TCPDUMP.md](../reference/network/TCPDUMP.md)）

## MCPとLLMの役割を比較する

ツールを呼ぶ必要のない質問とPicoNIXの状態を尋ねる質問を比較し，LLMがいつ`tools/call`を発行するか観察します．さらに，`host/mcp_client.py`（LLMなし）と本サンプル（LLMあり）を比較すると，MCP通信とツール選択の役割分担が理解できます．
