# vi — 簡易モード型エディタ

[English](../en/VI.md) | [文書一覧](DOCS.md) | [edit](EDIT.md)

`vi`は`edit`とは別の簡易モード型エディタです．`vi /tmp/hello.txt`で編集します．現在の対象は`/tmp`のRAMファイルで，RAMファイル自体は2048バイトまで保存できますが，現行の`vi`の編集バッファ上限は1024バイトです．完全なvi互換ではありません．

| 操作 | 意味 |
|---|---|
| `h`，`j`，`k`，`l` | 通常モードでカーソル移動 |
| 矢印キー（↑↓←→） | 通常モード・挿入モードの両方でカーソル移動 |
| `i`，`a` | 挿入モードに切り替え |
| `Esc` | 通常モードに戻る |
| `x` | 1文字削除 |
| `dd` | 1行削除 |
| `o` | 次の行を挿入 |
| `:w` | 保存 |
| `:q` | 終了 |
| `:q!` | 変更を破棄して終了 |
| `:wq` | 保存して終了 |

`dd`（通常モードでの行削除）と，ファイルコピー用の独立した[`dd`コマンド](DD.md)は別の機能です．

編集領域は行番号を表示せず，画面の左端から使用します．矢印キーはANSIエスケープシーケンスを送る端末で使用できます．
