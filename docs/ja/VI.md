# vi — 簡易モード型エディタ

[English](../en/VI.md) | [文書一覧](DOCS.md) | [edit](EDIT.md)

`vi`は`edit`とは別の簡易モード型エディタです．`vi /tmp/hello.txt`で編集します．編集できるのは`/tmp`直下のRAMファイルで，編集バッファの上限はRAMファイルと同じ2,048バイトです．完全なvi互換ではありません．読み込み時に2,048バイトを超えるデータを検出した場合は，内容を切り詰めずにエラーで終了します．

| 操作 | 意味 |
|---|---|
| `h`，`j`，`k`，`l` | 通常モードでカーソル移動 |
| 矢印キー（↑↓←→） | 通常モード・挿入モードの両方でカーソル移動 |
| `i`，`a` | 挿入モードに切り替え |
| `Esc` | 通常モードに戻る |
| `x` | 1文字削除 |
| `dd` | 1行削除 |
| `o` | 次の行を挿入 |
| `:w` | 保存 |
| `:q` | 終了 |
| `:q!` | 変更を破棄して終了 |
| `:wq` | 保存して終了 |

`dd`（通常モードでの行削除）と，ファイルコピー用の独立した[`dd`コマンド](DD.md)は別の機能です．

編集領域は行番号を表示せず，画面の左端から使用します．矢印キーはANSIエスケープシーケンスを送る端末で使用できます．

## はじめての編集

1. `vi /tmp/hello.txt`で起動します．
2. `i`を押して文字を入力します．
3. `Esc`を押して通常モードに戻ります．
4. `:wq`を入力し，Enterで保存して終了します．
5. `cat /tmp/hello.txt`で内容を確認します．

未保存の変更があるとき，`:q`は終了せず警告を表示します．変更を破棄する場合だけ`:q!`を使用します．`Ctrl+C`による終了は保存しません．
