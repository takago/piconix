# PicoNIX 簡易Thumbアセンブラ

PicoNIX上で小さなCortex-M0+のThumb-1プログラムをアセンブルし，`/tmp/a.out` に保存して実行できます．**教育・実験用の機能**であり，ELF，リンカ，動的ライブラリ，メモリ保護には対応しません．

## 使い方

シェルの初期ディレクトリは `/tmp` です．`cat > test.s` で次のコードを入力し，Ctrl+Dで保存します．

```asm
	@ getpid() を呼び出す（結果は r0 に返る）
	movs	r0, #1		@ システムコール番号1: getpid
	svc	#0

	@ プログラムを明示的に終了する
	movs	r0, #3		@ システムコール番号3: exit
	movs	r1, #0		@ 終了ステータス0
	svc	#0
```

```text
piconix# as test.s
as: 10 bytes (18 total) -> /tmp/a.out
piconix# ./a.out
```

`svc #0` の直前の `r0` がシステムコール番号です．上の例では `getpid`（番号1）を呼び出し，結果を `r0` に受け取ります．その後，`exit(0)`（番号3）で終了します．`bx lr` はサブルーチンから呼び出し元へ戻る命令であり，プログラムの終了には使いません．

## 文字列の表示

```asm
	@ 標準出力に "Hello\n" を表示する
	movs	r0, #9		@ システムコール番号9: write
	movs	r1, #1		@ ファイル記述子1: 標準出力
	adr	r2, msg		@ 文字列のアドレス（PC相対）
	movs	r3, #6		@ 表示するバイト数
	svc	#0		@ write(1, msg, 6)

	@ exit(0) で終了する
	movs	r0, #3		@ exit
	movs	r1, #0		@ 終了ステータス
	svc	#0

	.align	2		@ msg を4バイト境界に配置
msg:
	.ascii	"Hello\n"
```

`write`（番号9）には `r1` にFD，`r2` にバッファ，`r3` に長さを指定します．文字列はコードと同じ位置独立イメージ内に配置します．`adr` は前方の4バイト境界に配置されたデータへの参照のみ対応します．このプログラムは22バイト（ヘッダ込み30バイト）です．

## 対応構文

- `movs rN, #IMM`，`adds rN, #IMM`，`subs rN, #IMM`，`cmp rN, #IMM`：`r0`〜`r7`，即値0〜255
- `b LABEL`，`beq LABEL`，`bne LABEL`：PC相対分岐
- `adr rN, LABEL`：前方の4バイト整列ラベルへのPC相対アドレス取得
- `svc #IMM`，`bx lr`，`nop`
- `LABEL:`，`.align 2`（4バイト境界），`.ascii "text"`（`\n`，`\r`，`\t`，`\\`を利用可能）
- コメントは `@` または `;`，命令は各行に1つ

## 制約と注意

- `/tmp` は最大4ファイル，各1024バイトです．生成ファイルには8バイトのヘッダが付き，コード・データは最大1016バイトです．
- ラベルは最大32個です．分岐距離や即値がThumb-1の範囲外ならエラーになります．
- `as` は常に `/tmp/a.out` を上書きします．実行時に引数を渡す機能はありません．
- 現在は単一の位置独立イメージのみ扱います．絶対アドレスの埋め込み，リロケーション，外部シンボルはサポートしません．
- `/tmp` の内容は揮発性です．`./a.out` を実行すると，カーネルがイメージを空きRAMスロットにコピーします．
- **任意の機械語はメモリを破壊する可能性があります**．RP2040には一般的なプロセスメモリ保護がないため，信頼できる実験コードだけを実行してください．

## 追加したThumb-1命令

- `mov rD, rS`：レジスタ間転送（現在の簡易構文では`r0`〜`r7`）
- `ldr` / `str`：`ldr r0, [r1]`，`str r0, [r1, #4]` など，レジスタ基準の32bitアクセス（オフセット0〜124，4の倍数）
- `ldrb` / `strb`：8bitアクセス（オフセット0〜31）
- `push {r4, lr}` / `pop {r4, pc}`：`r0`〜`r7` と追加の `lr` または `pc`
- `bl label`：同じイメージ内のサブルーチン呼び出し（本実装では近距離に限定）
- `bcc label` / `bcs label`：符号なし比較の条件分岐
- `.byte N`，`.word N`，`.space N`：バイト，整列済み32bit値，ゼロ初期化した領域

`ldr` と `str` 自体にPIC固有の指定は不要ですが，スロット内のデータアドレスは `adr` で取得してください．`.word` の前には必要に応じて `.align 2` を置きます．
アセンブル成功時は，機械語・データのサイズと8バイトのヘッダ込みの総サイズを表示します．

```text
as: 24 bytes (32 total) -> /tmp/a.out
```

[アセンブリサンプル集](../../userland/examples/asm/ja/README.md)に，文字列表示，スタック操作，0〜255の整数表示の例があります．
