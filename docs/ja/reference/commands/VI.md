# vi — 簡易モード型エディタ

*操作ガイド*

**最初に読むポイント：** キー入力で文字を挿入する前に「通常モード」と「挿入モード」の違いを確認してください．誤操作した場合は `Esc` で通常モードに戻ります．


`vi`は`edit`とは別の簡易モード型エディタです．`vi /tmp/hello.txt`や`vi /etc/rc`で編集します．編集できるのは`/tmp`または`/etc`直下のRAMファイルで，編集バッファの上限はRAMファイルと同じ2,048バイトです．完全なvi互換ではありません．読み込み時に2,048バイトを超えるデータを検出した場合は，内容を切り詰めずにエラーで終了します．

| 操作 | 意味 |
|---|---|
| `h`，`j`，`k`，`l` | 通常モードでカーソル移動 |
| 矢印キー（↑↓←→） | 通常モード・挿入モードの両方でカーソル移動 |
| `i`，`a` | 挿入モードに切り替え |
| `Esc` | 通常モードに戻る |
| `x` | 1文字削除 |
| `dd` | 1行削除 |
| `o` | 次の行を挿入 |
| `:w` | 保存 |
| `:%s/OLD/NEW/g` | ファイル全体の文字列を一括置換（正規表現ではない） |
| `:q` | 終了 |
| `:q!` | 変更を破棄して終了 |
| `:wq` | 保存して終了 |

`dd`（通常モードでの行削除）と，ファイルコピー用の独立した[`dd`コマンド](DD.md)は別の機能です．

編集領域は行番号を表示せず，画面の左端から使用します．矢印キーはANSIエスケープシーケンスを送る端末で使用できます．

## 編集操作例

1. `vi /tmp/hello.txt`で起動します．
2. `i`を押して文字を入力します．
3. `Esc`を押して通常モードに戻ります．
4. `:wq`を入力し，Enterで保存して終了します．
5. `cat /tmp/hello.txt`で内容を確認します．

未保存の変更があるとき，`:q`は終了せず警告を表示します．変更を破棄する場合だけ`:q!`を使用します．`Ctrl+C`による終了は保存しません．

## MCPからの操作と置換

まず `get_manual({"topic":"vi"})` でPicoNIX固有の操作を確認します．`terminal_send({"text":"vi /tmp/test.txt"})`と`terminal_send({"key":"ENTER"})` で起動し，`terminal_read({})` で画面を取得します．`execute_command` で対話型エディタを直接起動しないでください．

`1000` を `100` に一括置換するには，通常モードで次の順に送ります．

```text
terminal_send({"key":"ESC"})
terminal_send({"text":":%s/1000/100/g"})
terminal_send({"key":"ENTER"})
terminal_read({})
terminal_send({"key":"ESC"})
terminal_send({"text":":wq"})
terminal_send({"key":"ENTER"})
```

置換は**文字列の完全一致**であり，通常のVimの正規表現機能ではありません．区切り文字 `/` を含む文字列や複雑な置換式は扱えません．置換後に2,048バイトを超える場合は変更されません．`:help`で短い操作一覧を表示できます．`:set`，Undo，`/pattern`などは未実装です．`terminal_send`の成功だけで保存済みとは判断せず，終了後に`cat /tmp/test.txt`で検証してください．`terminal_read`は毎回現在画面を返しますが，それだけでは保存成功を示しません．
