# reversi

`reversi`は8×8の盤面でCOMと対戦するリバーシゲームです．通常のTTYとMCPが用意するPTYのどちらでも同じように動作します．

```sh
reversi
```

矢印キーでカーソルを動かし，SPACEで黒石を置きます．`q`で終了します．`h`，`j`，`k`，`l`でもカーソル移動できます．不正な着手は無効となり，COMは合法手から盤面評価で一手を選びます．打てる手がない場合は自動パスし，両者が打てなくなれば終了します．

MCPでは`terminal_open`で`reversi`を起動し，`terminal_read`で画面を確認して，`terminal_send`から矢印キーとSPACEを送信します．`terminal_send`は描画完了を待たないため，必要に応じて`terminal_read`で手番と盤面を確認します．ゲームにMCP専用コードはありません．

最新の着手位置は，既存の3文字幅のマスを利用して`[B]`または`[W]`と表示します．カーソルの反転表示（SGR 7）は維持します．黒の着手後には`Turn: COM`と`COM is thinking...`を表示して約1秒待ち，その後に白の応手を描画します．パスした場合は最後に石を置いた位置を維持します．MCPからは`Turn: PLAYER`を確認して次の操作を行ってください．

不正着手は，空きマスで石を反転できない場合と，すでに石があるマスでSPACEを押した場合に各1回加算されます．画面には`Invalid moves: PLAYER n  COM m`として，両者の回数を常時表示し，終局時にも残します．カーソル移動や自動パスでは加算されません．COMは合法手だけを選ぶため，通常は0回です．
