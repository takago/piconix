# `reversi`：リバーシ

`reversi`は8×8盤面でPLAYER（黒石`B`）とCOM（白石`W`）が対戦する対話型ゲームです．通常のTTYとMCPのPTYで共通の端末画面を使用します．**非対話の`execute_command`では起動しないでください**．

```sh
reversi
```

## 操作

| キー | 動作 |
|---|---|
| 矢印キー，`h`／`j`／`k`／`l` | カーソル移動（左／下／上／右） |
| SPACE | カーソル位置へ黒石を置く |
| `q`／`Q` | ゲームを終了する |

相手の石を1枚以上反転できる場所にだけ置けます．置けない場所でSPACEを押した場合は盤面を変更せず，PLAYER側の不正着手回数を増やします．

## 盤面と表示

- `B`が自分の黒石，`W`がCOMの白石，`.`が空きマスです．上にa〜h，左に1〜8の座標があります．
- 直近の着手は`[B]`または`[W]`と表示します．カーソル位置は反転表示（ANSI SGR 7）で示します．パス時は最後に置かれた石の印を維持します．
- 石の数，手数，`Invalid moves: PLAYER n  COM m`（各陣営の不正着手回数），手番が表示されます．カーソル移動と自動パスは不正着手に含めません．COMは合法手から選ぶため通常は0回です．
- 黒の合法手の直後，`Turn: COM`／`COM is thinking...`を表示して約1秒待ってから白の応手を表示します．`Turn: PLAYER`で次の入力を受け付けます．

## パスと終局

COMは着手可能な場所がなければ自動的にパスします．PLAYERが着手不能なときも自動パスし，COMが続けて着手する場合があります．両者とも着手できなくなると勝敗または引分けを表示します．終局後は`q`で終了します．

## MCPから操作する場合

`terminal_send({"text":"reversi"})`と`terminal_send({"key":"ENTER"})`で開始し，`terminal_read({})`で80×24画面と`Turn:`を読み，`terminal_send({"key":"SPACE"})`などで操作します．キー入力の送信完了は**描画やCOMの応手完了を意味しません**．必要な時点で再度`terminal_read({})`を呼び，`Turn: PLAYER`と盤面を確認します．終了時は`q`でゲームを終了し，常駐PTYのシェルへ戻ります．ゲーム本体にはMCP専用処理はありません．
