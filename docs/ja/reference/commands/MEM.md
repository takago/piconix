# mem — 読み取り専用メモリビューア

*操作ガイド*

`mem` はPicoNIXのSRAMやXIP Flashを16進数で観察する全画面コマンドです．**読み取り専用で，メモリを編集・書き換える機能はありません**．

## はじめに表示してみる

```sh
mem
```

起動すると，アドレスと，その位置にあるバイト列が表示されます．**1行は16バイト**です．約1秒ごとに `/dev/mem` から読み直し，前回と異なる値を反転表示します．反転表示は値が変わったことを意味し，`mem` が書き換えたことを意味しません．

```sh
mem 0x20018000
```

引数には開始アドレスを指定できます．閲覧できる範囲は `/dev/mem` が許可するXIP Flash `0x10000000`～`0x101fffff`，SRAM `0x20000000`～`0x2003ffff` です．範囲外のアドレスは表示できません．

## 画面を操作する

| キー | 動作 |
|---|---|
| `↑` / `↓` | 16バイト（1行）移動 |
| `PgUp` / `PgDn` | 表示中の1画面分移動 |
| `SPACE` | 周期的な更新を停止・再開 |
| `1`～`6` | 対応する24 KiBのユーザタスクスロットへ移動 |
| `k` | カーネルRAMへ移動 |
| `K` | XIP Flashへ移動 |
| `g` | 16進アドレスを入力して移動 |
| `q` | 終了 |

表示行数は端末の高さから見出し3行と操作案内3行を引いて決まります．1行16バイト，最大36データ行（576バイト）です．24行端末では18データ行（288バイト）になります．端末サイズが取得できない場合は80×24を仮定します．実行中の端末サイズ変更には追従しません．

## シンボル名からアドレスを理解する

```sh
mem -s
mem -s kernel
mem -s sh
```

`mem -s` は利用可能なシンボル情報源を表示し，`mem -s kernel` はカーネル，`mem -s sh` はシェルのシンボルを表示します．通常のメモリ閲覧中にも，現在のアドレスに対応するシンボルが表示されます．シンボルは「このアドレス付近にどの関数・データがあるか」を知るための補助情報であり，すべてのアドレスに名前があるわけではありません．シンボル情報が利用できなくても，メモリ閲覧自体は続けられます．

**トレースとの違い：** `mem -s kernel` のシンボル表はリンク済みELFから生成された名前とアドレスの情報です．`kernel/kernel.c` の `TRACE_MATCH` は関数トレースの記録対象を選ぶ別の仕組みであり，シンボル表を使って選別しているわけではありません．詳しくは [トレースガイド](TRACE.md) を参照してください．

## 観察するときの注意

- 実行中のRAMは他のタスクが更新します．一度に取得した完全なスナップショットではありません．
- `1`～`6` で移動するユーザ領域は，タスクの起動・終了に応じて内容が変化します．
- `k` のカーネルRAMと `K` のXIP Flashは用途が異なります．カーネルコードの多くはFlashからXIP実行されます．
- 画面表示が更新されなくなった場合は，まず `SPACE` による一時停止状態を確認してください．
