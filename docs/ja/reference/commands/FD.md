# fd — ファイルブラウザ

*操作ガイド*

`fd` は，端末上でディレクトリを移動し，ファイルの内容を確認するための小型フルスクリーンブラウザです．FDclone風の操作ですが，Linuxのファイルマネージャと同じ機能がすべてあるわけではありません．

## 起動する

```sh
fd
fd /etc
fd /proc
fd /man
```

`fd` だけならシェルのカレントディレクトリから始まります．引数にディレクトリを指定すると，そこから閲覧します．**ANSIカーソルキーを扱える端末**で使用してください．

## 一覧での基本操作

| キー | 操作 |
|---|---|
| `↑` / `↓` | 項目を選択 |
| `Enter` / `→` | ディレクトリに入る，またはファイルを開く |
| `←` / `Backspace` | 親ディレクトリへ移動 |
| `../` を選んで `Enter` | 親ディレクトリへ移動 |
| `/` | ファイル名の部分一致検索（入力中に絞り込み） |
| `Enter` / `Esc`（検索中） | 検索を確定／取り消す |
| `c` | 検索条件を消去して全件表示 |
| `r` | 一覧を再読み込み |
| `e` | 選択中のファイルを `edit` で編集（編集可能なファイルのみ） |
| `q` | 終了 |

`/` を押して `trace` などを入力すると，一致した名前だけを表示します．大文字・小文字は区別しません．48件を超えるディレクトリは `↓` で次の一覧へ進み，`↑` で前の一覧へ戻ります．検索対象は**現在のディレクトリのファイル名**であり，本文検索ではありません．

例えば `fd /proc` で一覧を開き，矢印キーで項目を選び，`Enter` で内容を確認します．戻るときは `←`，`q` または `Esc` です．**一覧画面の `q` は終了，ファイル閲覧画面の `q` は一覧への復帰**であり，動作が異なります．

## ファイルを閲覧する

`/tmp`，`/etc`，`/proc`，`/man` のファイルでは，`Enter` で読み取り専用ビューアが開きます．`/proc`などは約1秒間隔で再読み込みされ，更新される値の観察に使えます．ROM内の`/man`は静的なため再読み込みしません．

| キー | ビューアでの操作 |
|---|---|
| `↑` / `↓` | 1行ずつスクロール |
| `PgUp` / `PgDn` | 1画面ずつスクロール |
| `/` | 表示中のテキスト本文を検索（大文字小文字を区別しない） |
| `Enter` / `Esc`（検索入力中） | 検索開始／取り消し |
| `n` / `N` | 次／前の一致行へ移動（末尾・先頭で折り返す） |
| `e` | 編集可能なら `edit` を起動 |
| `←` / `q` / `Esc` / `Backspace` | ファイル一覧へ戻る |

閲覧画面で`/`を押し，例えば`socket`を入力して`Enter`を押すと，本文の最初の一致行へ移動します．一致した文字列は反転表示され，`n`で次，`N`で前の一致行を検索します．検索は行単位の部分一致で，ファイル名の絞り込みとは別の機能です．検索時はファイルを先頭から順次読み，全文をRAMに保存しません．

表示対象はテキストを想定し，制御文字などは `.` に置き換えます．長い行は端末の表示幅で切り詰めます．**ビューアはファイルを変更しません**．バイナリ内容を詳しく見る場合は `hexdump` を使ってください．

## 編集する

`/tmp` または `/etc` の直下にある編集可能なRAMファイルを選び，`e` を押すと `edit` が起動します．`edit` を通常どおり終了すると `fd` の一覧に戻ります．閲覧中に `e` を押す方法もあります．

`fd` は編集の前に標準入力の非ブロッキング設定を解除し，編集後にはブラウザ用の設定を復元します．ただし `/proc`と`/man` は観察用であり，この操作で編集できません．詳しくは [editガイド](EDIT.md) を参照してください．

## MCPからの操作

`get_manual({"topic":"fd"})`でキー操作を確認し，`terminal_open({"command":"fd /tmp"})`で開始します．`terminal_read({})`で画面を確認してから，`terminal_send({"key":"DOWN"})`などを送信します．**一覧画面とファイル閲覧画面で`q`の動作が違う**ため，画面遷移のたびに`terminal_read`で確認してください．`fd`の`e`は`vi`ではなく`edit`を起動します．`vi`で編集したい場合は`fd`を終了し，`terminal_open({"command":"vi /tmp/NAME"})`で新しいセッションを開きます．

## 制限と内部動作

- 一覧は48件ずつ読み込んで表示します．48件を超えるディレクトリは矢印キーで次／前の区間へ移動できます．検索は一覧全件に対して適用され，表示枠を超えた一致項目も辿れます．最大画面サイズは40行×110列です．
- コピー，削除，名前変更，移動はできません．必要なら対応するシェルコマンドを使います．
- `/dev` のデバイスノードは，読み取りに副作用や待機があり得るため，ビューアから開きません．
- `../` はVFSの `getdents()` から取得されます．`.` は非表示で，ルートでは `..` を表示しません．
- 2 KiBの表示用バッファには現在の範囲だけを保持します．本文検索も128バイト単位の読み取りで行い，検索語は最大31文字です．一致判定は行単位で，改行をまたぐ文字列は検索しません．
- `/proc/sym/kernel`と`/man`の文書では，`lseek()` 対応時に16行ごとの位置を最大128件索引化して移動を高速化します．別ファイルを開くときや `r` を押したときは索引を破棄します．索引範囲外でも順次読み取りで閲覧可能です．他の `/proc` ファイルや `lseek()` 非対応環境では順次読み取りを使います．

**困ったとき：** キーが効かない場合はANSI対応の端末を使っているか確認してください．一覧に目的のファイルがない場合は，`c`で検索条件を解除し，次のページも確認してください．本文検索は閲覧画面で`/`を押してください．シェルからまとめて調べるには`grep PATTERN /man/FILE`も利用できます．
