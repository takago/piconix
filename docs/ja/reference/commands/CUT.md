# cut — 区切り文字による列抽出

`cut`は，標準入力またはファイルの各行を区切り文字で分割し，指定した列を抽出します．正規表現や引用符付きCSVの解釈は行いません．

```text
cut [-d CHAR] -f LIST [FILE]
```

- `-d CHAR`：区切り文字（ちょうど1バイト）．省略時はタブ．
- `-f LIST`：1から数える列番号（必須）．カンマ区切りの番号または閉区間（例：`1,3-5`）を指定．対象は1〜64列．
- `[FILE]`：省略すると標準入力を読み込みます．

```sh
cut -d, -f1,4 /tmp/data.csv
cat /tmp/data.csv | cut -d, -f2-3
```

選択列は元の順序で出力し，出力列間には区切り文字を挿入します．存在しない列は無視し，区切り文字を含まない行はそのまま出力します．入力行が512バイトを超える場合はエラーで終了します．引用符付きCSV，複数バイト区切り，空白を含むフィールド名には対応しません．書込みが部分成功した場合は残りを再試行します．

`cut`は区切り文字を持つテキストに使用します．`/proc/cpu`は固定幅の表形式なので，CSV用の列抽出には使用できません．
