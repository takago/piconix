# `samegame`：A・B・Cのブロック消去ゲーム

`samegame`は，20×12マスに配置された`A`，`B`，`C`の**3種類の文字ブロック**を消すパズルです．色の表示機能は不要です．80×24文字の端末に収まります．上下左右につながった同じ文字が2個以上ある部分を選択すると，そのグループ全体が消えます．残ったブロックは下に落ち，空になった列は左側に詰まります．

```sh
samegame                 # SysTick由来のシードで新しい盤面
samegame -s 1234         # シード1234の盤面を再現
```

| 入力 | 動作 |
|---|---|
| 矢印キー，`h`／`j`／`k`／`l` | ブロック選択 |
| SPACE | 選択した連結グループを消す |
| `:a01`，`:t12` | 指定座標のグループを直接消す．行は必ず2桁で指定し，Enter不要 |
| `r` | 再挑戦（通常は新シード，`-s`時は同じ盤面） |
| `q` | 終了 |

画面には`Seed`，`Score`，`Best`，`Best seed`，`Remaining`，`Groups removed`，`Selection`，`Group`，`Invalid`を表示します．`Best`は起動から終了までの最高得点で，得点更新時に自動更新され，`r`で再挑戦しても消えません．`Best seed`はその得点を記録した盤面のシードで，同じ盤面を再現できます．`q`でプロセスを終了すると記録は失われ，ファイルには保存しません．列は`a`〜`t`，行は`01`〜`12`です．座標指定は行を2桁で入力します（例：`:b03`）．`Group`はカーソル位置の連結ブロック数です．1個だけの選択や空欄の指定は失敗となり，`Invalid`が増えます．選択できるグループがなくなれば終了です．すべて消す必要はありません．

得点は，1手で`n`個消すと`(n−2)²`点で，全ブロックを消した場合は1000点を追加します．通常起動と`r`の新盤面は`/proc/ticks`を種にした疑似乱数です．同じシードなら同じ初期配置になります．

MCP操作では**`execute_command`で起動せず**，常駐PTYから起動してください．`terminal_send`の文字列で`:a01`のように送ればカーソルキー操作を省略できます．消去後は列が動くため，次の着手前に`terminal_read`で盤面を再確認してください．
