# `maze`：迷路ゲーム

`maze`は21×9の迷路を自動生成し，`@`を出発地点（1,1）からゴール`G`（17,7）へ移動させるゲームです．`#`は壁です．相手COMは存在せず，LLMの画面認識，経路計画，キー操作を切り分けて評価できます．

```sh
maze             # /proc/ticks（1 ms SysTick）をシードに毎回生成
maze -s 1234     # 同じ迷路を再現する
```

起動時と通常モードでの`r`キー操作時に，カーネルの`/proc/ticks`を読み取り，乱数生成器の初期値として使います．同じシードなら迷路は再現されます．画面上部に表示される`Seed`を記録すれば，後から`maze -s <Seed>`で同じマップを再現できます．同じ1 ms内の再生成ではシードを1増やすため，少なくともシード値は切り替わります．`-s`指定時の`r`は**同じ迷路に再挑戦**します．SysTickの値は暗号学的な乱数ではありません．

迷路は深さ優先探索で全通路を接続した「完全迷路」として生成し，ゴールには必ず到達できます．生成されたマップごとに幅優先探索（BFS）で最短手数を算出します．

| キー | 操作 |
|---|---|
| 矢印キー，`h`／`j`／`k`／`l` | 上下左右への1マス移動 |
| `r` | 通常モードは新しい迷路，`-s`指定時は同じ迷路で再開．カウンタは初期化 |
| `q` | 終了 |

座標は左上を（0,0）とし，`Player: (x,y)`で現在位置を表示します．`Moves`は**成功した移動回数**で，壁への移動要求は`Wall hits`を増やしますが位置と`Moves`は変えません．`Shortest`はその迷路の最短手数です．ゴール後には`Extra moves`と`Efficiency`（`100 × Shortest / Moves`の整数部分）を表示します．ゴール後の移動操作は無視され，`r`で再開できます．

MCPでは非対話`execute_command`から起動せず，`terminal_send`／`terminal_read`でPTYを操作します．矢印キー1回ごとに画面を読み取ると操作ミスを分析しやすくなります．実験を再現する場合は画面の`Seed`を保存してください．
