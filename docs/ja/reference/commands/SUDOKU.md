# `sudoku`：4×4・9×9数独

`sudoku`は，行・列・小ブロックに同じ数字を重複させずに空欄を埋める，1人用の数独パズルです．標準は9×9（数字1〜9，3×3ブロック），`-4`を付けると4×4（数字1〜4，2×2ブロック）です．

```sh
sudoku                 # 標準9×9，SysTick由来のシード
sudoku -4              # 入門用4×4
sudoku -4 -s 1234      # 同じ4×4の問題を再現
sudoku -s 1234         # 同じ9×9の問題を再現
```

各サイズに**解が1つの基礎問題**を内蔵しています．シードを使い，数字の置換，同じ帯内の行・列入替，帯の入替，転置によって問題を変形します．これらは数独の解の一意性を保存しますが，無限に独立した新問題を生成する方式ではありません．固定数字は変更できませんが，プレイヤーの入力欄には範囲内の数字なら自由に入力でき，重複があってもそのまま残ります．隠された解答との逐次照合はしません．`Conflicts`は行・列・ブロックで重複している数字があるマスの数で，`Rejected`は固定マスの変更など受け付けなかった操作の回数です．すべて埋まり規則違反がなくなれば完成です．

画面では固定数字を` 5 `のように括弧なしで表示し，入力可能な空欄は`[ ]`，プレイヤーが入力した数字は`[3]`と表示します．これらは色や反転表示に依存しないため，MCPの`terminal_read`でも区別できます．`Cursor`には選択座標を文字で表示します．


4×4の表示例（`-s 12345`）です．固定数字には括弧が付かず，編集可能なマスだけが括弧で囲まれます．

```text
     a   b     c   d
   +--------+ --------+
 1 |[ ]  3  |  2  [ ] |
 2 | 4  [ ] | [ ]  1  |
   +--------+ --------+
 3 | 2  [ ] |  1  [ ] |
 4 |[ ]  1  | [ ]  2  |
   +--------+ --------+
```

| 入力 | 動作 |
|---|---|
| 矢印キー，`h`／`j`／`k`／`l` | 選択マスを移動 |
| `1`〜`9`（4×4は`1`〜`4`） | 数字を入力 |
| `0`またはSPACE | 編集可能なマスの数字を消す |
| `:a1=2` | `a1`へ直接`2`を入力．`0`なら消去．Enter不要 |
| `r` | 問題とカウンタを再初期化 |
| `q` | 終了して端末設定を復元 |

`-s`なしの`r`は`/proc/ticks`（1 ms単位のSysTick計数）を読み直して別シードの問題を表示します．`-s`指定時は同じ問題を再表示します．使用シードは画面に表示されます．乱数は暗号用ではありません．

MCP経由では**`execute_command`を使用せず**，常駐PTYの`terminal_send`で起動し，`terminal_read`で画面を確認してください．直接入力の`:a1=2`を`terminal_send`の文字列として送ると，カーソル移動と数字入力をまとめられます．位置・数字を実際の表示で確認してください．
