# CPU負荷履歴（`/proc/cpu`）

`/proc/cpu`は，直近30秒間のCPU負荷を1秒ごとに記録した読み取り専用の**固定幅テキスト表**です．新しい計測結果から順に，最大30行を表示します．CSV形式ではありません．

```sh
cat /proc/cpu
watch 1 cat /proc/cpu
```

```text
       |                CPU Usage (%)                 |                  CPU Time (ms)                  
Time   |    Idle    Busy  ( Console    Task    Net )  |      Idle     Busy  ( Console     Task     Net )
-------+----------------------------------------------+-------------------------------------------------
   26s |    93.7     6.3  (     2.3     0.0     4.0)  |     936.9     63.1  (    22.8      0.0     40.3)
   25s |    93.9     6.1  (     2.1     0.0     3.9)  |     939.3     60.7  (    21.4      0.0     39.4)
```

数値は説明用です．`Time`は起動後の経過秒数です．一行は**終了した直近1秒間**の測定結果を表します．起動後最初の1秒は見出しだけを返します．

| 項目 | 意味 |
|---|---|
| `Idle` | 計測した処理時間を1秒から差し引いた残りの概算値．実際のスリープ時間の実測値ではありません |
| `Busy` | `Console`，`Task`，`Net`の合計（1秒を上限に補正） |
| `Console` | Idleタスク内の`os_console_poll()`の経過時間．`/dev/console`への転送時間そのものではありません |
| `Task` | SysTickが1 ms粒度で標本化した，Idle以外のタスクの時間 |
| `Net` | Idleタスク内の`net_poll()`の経過時間．Telnetの通信時間全体を表すものではありません |

左側の`CPU Usage (%)`は小数第1位の百分率，右側の`CPU Time (ms)`は小数第1位のミリ秒です．計測値はカーネル内部でマイクロ秒単位（Taskのみ1 msの標本化）で保持し，整数演算で表示値へ換算します．表示の丸めにより，内訳の合計と`Busy`に小さな差が生じることがあります．割込み時間，測定オーバーヘッド，Idle以外で実行されたネットワーク処理は厳密には分離していません．**実際のCPU使用率を厳密に示すものではなく，負荷傾向を見るための概算値です．**

読み取りでは履歴を消去しません．`open()`時の記録順序を保持し，`read()`による分割取得にも対応します．読み取りに30秒以上かかってリングバッファが上書きされた場合は，該当する古い行が欠けることがあります．通常のPicoでは`Net`は空の`net_poll()`呼び出しのオーバーヘッドのみで，Wi-Fiの負荷ではありません．

Pico Wでは，250 µs周期のタイマー割込みとIdleタスクの`WFI`を組み合わせ，ポーリング中の空回りを抑えています．通信処理は割込み内ではなくCore 0のIdleタスクで行います．将来Core 1を使う場合でも，この表は現状Core 0だけを対象とします．

## タスク別CPU時間

`/proc/tasks`にはIdleを含むタスク別累積`CPU_TICKS`（1tick＝1ms）を掲載します．`top`の`CPU%`は前回の読取りからの増分を経過時間で割った概算値です．Idleの行はPID 0・`[idle]`です．CPU割り込み・カーネルの実行時間を正確にプロセスへ分離する計測ではなく，`/proc/cpu`のConsole・Net内訳との合計が厳密には一致しないことがあります．
