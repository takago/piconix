# 教育用Cサブセットコンパイラ `cc`

*開発・言語リファレンス（現行ソース：`userland/apps/cc.c`）*

`cc`はPicoNIX上で動作する小型のCサブセットコンパイラです．`.c`ファイルをPicoNIX独自のThumb-1アセンブリ（`.s`）へ変換し，`as`で実行ファイルを作成します．**ISO C／GCCとの互換性はありません**．

## コンパイルと実行

`edit /tmp/hello.c`などで次のファイルを作成します．`cat > /tmp/hello.c`で入力する場合はCtrl+Dで終了します．

```c
int main(void) {
    write(1, "Hello, PicoNIX!\n", 16);
    return 0;
}
```

```sh
cc /tmp/hello.c
cat /tmp/hello.s
as /tmp/hello.s
/tmp/a.out
```

`cc`は入力の末尾`.c`を`.s`に置き換えた**同一ディレクトリ**のファイルを生成します．`as`が生成する実行ファイルは`/tmp/a.out`です．コンパイルまたはアセンブルが失敗した場合，**古い`/tmp/a.out`を誤って実行しないでください**．生成した`.s`で`svc #0`や分岐を観察できます．

## 対応する構文

| 項目 | 対応範囲 |
|---|---|
| 関数 | `int main()`／`int main(void)`必須．`int`／`void`関数の定義・呼出し・再帰的呼出しのコード生成．前方呼出し可．定義は最大16個，呼出し箇所は最大32個 |
| 引数と戻り値 | 引数は最大4個で`int`，`int *`，`char *`に限定．`int`関数は`return 式;`，`void`関数は`return;`が使用可能．ポインタ戻り値は不可 |
| 局所変数 | `int`（32ビット），`char`（1バイト），`int`／`char`の1次元配列，1段階のポインタ．関数当たり名前は最大16個，局所領域合計256バイト |
| 配列 | `a[i]`の読書き，`sizeof(a)`，`char s[6] = "HELLO";`などの初期化．配列長は1〜64要素，添字境界検査なし |
| 式 | 変数，整数・文字定数，括弧，単項`+`／`-`，`+`／`-`／`*`／`/`／`%`，`sizeof(局所変数)` |
| 比較・制御 | `==`，`!=`，`<`，`<=`，`>`，`>=`による**符号付き32ビット比較**．`if`／`else`／`while`（本体は`{}`必須） |
| ポインタ | `&x`，`&a[i]`，`*p`，`*p = 値`，`p[i]`，`p + n`，`p - n`．配列名をポインタ引数へ渡せる．`int *`の加減算は4バイト単位，`char *`は1バイト単位 |
| 増減演算子 | **`int`型の単一局所変数**に限り，`++i`，`i++`，`--i`，`i--`（式中・単独文） |
| システムコール | `getpid();`，`read(fd, buffer, count)`，`write(fd, buffer, count)`．FDとcountは整数式，bufferは配列名・局所変数のアドレス・対応ポインタ式 |
| コメント | `//`，`/* ... */` |

10進整数定数は正の値が`0`〜`2147483647`です．負の値は単項`-`で構成できます．32ビットの最大値を超える定数や式のオーバーフローは通常のCと同じ動作を保証しません．文字定数では一部のエスケープを扱います．

### ポインタと関数の例

```c
void swap(int *a, int *b) {
    int t;
    t = *a;
    *a = *b;
    *b = t;
}
int main(void) {
    int x = 10;
    int y = 20;
    swap(&x, &y);
    if (x == 20) { write(1, "OK\n", 3); }
    return 0;
}
```

この例を`/tmp/swap.c`として保存し，`cc /tmp/swap.c` → `as /tmp/swap.s` → `/tmp/a.out`の順に実行します．配列要素のアドレスは`&a[i]`で取得できます．`read(0, &c, 1)`のように，単一の`char`変数をバッファにすることもできます．

### 配列と実行時の書込みバイト数

```c
int main(void) {
    char buf[16];
    int n = read(0, buf, sizeof(buf));
    if (n > 0) { write(1, buf, n); }
    return 0;
}
```

`read`の戻り値で実際に取得したバイト数を判断します．実行時にバッファ長を検査する機能はないため，`write(1, buf, 16)`のように未初期化部分まで送らないよう注意してください．

### 条件分岐と`++`／`--`

```c
int main(void) {
    int i = 0;
    while (i < 3) {
        if (i <= 1) { write(1, "A\n", 2); }
        else { write(1, "B\n", 2); }
        i++;
    }
    return 0;
}
```

前置演算子は更新後の値，後置演算子は更新前の値を式の結果にします．ただし，`char`変数，配列要素，`*p`，ポインタ変数への`++`／`--`は非対応です．

## 文字列リテラルと`read`／`write`

`write(1, "HELLO", 3);`は特別な定数文字列形式で，FDは0〜2の整数定数，長さは文字列の実バイト数以下の非負整数定数に限定されます．`"HELLO"`の指定長3なら`HEL`だけを出力します．`\n`，`\r`，`\t`，`\\`には対応しますが，`\"`は扱いません．

`write(fd, buf, n)`の一般的な3引数形式では，FDと長さを式で指定でき，バッファに配列名・`&`を用いた局所変数のアドレス・ポインタ式を使用できます．`read`は受信バイト数を式中で利用可能です．実行時の書込み範囲をカーネル／コンパイラが自動的に検証するわけではありません．

## 未対応・制限

- **未対応：** `#include`とプリプロセッサ，一般的なライブラリ呼出し，グローバル変数，`struct`／`union`／`enum`，`typedef`，`const`／`static`，`for`，`switch`，`do`，`&&`／`||`，三項演算子，キャスト，`+=`などの複合代入，関数プロトタイプだけの宣言．ブロックスコープの一般的な名前の隠蔽もありません．
- **ポインタの制約：** 多重ポインタ（`int **`），ポインタの配列，ポインタ戻り値，ポインタ同士の減算，関数ポインタ，`malloc()`は非対応です．添字・ポインタ境界を検査しません．
- **除算・剰余：** 減算の反復で実装し，**非負整数の演算**に限って使用してください．0除算は0を返しますが，標準C互換ではなく，依存してはいけません．
- **容量上限：** 入力`.c`は1024バイト，生成アセンブリの内部バッファは4096バイトですが，**`.s`ファイルへ書き出せる上限は2048バイト**です．`as`の機械語ペイロード上限は2040バイト，ラベル上限は32個です．定数の生成や複数関数の使用で容易に上限へ達します．
- **実行上の注意：** PICアプリにはメモリ保護がありません．不正なポインタは他の領域を破壊するおそれがあります．エラー診断は限定的で，ABIの完全な互換性も保証しません．

## コンパイラとアセンブラの仕組み

式は`primary`→`unary`→`multiply`→`additive`の優先順位で再帰下降解析し，結果を`r0`に配置します．式の途中値は`push`／`pop`で保存します．関数の引数は最大4個で`r0`〜`r3`，戻り値は`r0`です．関数ごとに`push {r4, lr}`と固定256バイトフレームを使用し，`r4`を局所変数のフレームポインタにします．呼出し元へ戻った後，`main`の戻り値は起動スタブから`exit`システムコールへ渡します．`return`をすべて即時`exit`へ変換するわけではありません．

`read`はシステムコール番号8，`write`は9，`exit`は3で，`r0`に番号，`r1`〜`r3`に引数を配置して`svc #0`を発行します．`svc`の即値0はシステムコール番号ではありません．生成アセンブリの命令は2スペースでインデントし，ラベルとディレクティブは行頭に置きます．
