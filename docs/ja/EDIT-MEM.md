# edit と mem

## edit — 小さな画面エディタ

`edit /tmp/test.s` で編集します．ファイルがなければ新規作成します．
矢印キーでカーソルを移動し，Enterで改行，TABは4桁単位で表示します（保存時はTABのまま）．
Ctrl+Sで保存，Ctrl+Qで終了します．未保存の変更がある場合は終了を拒否します．
1ファイル最大1,024バイト，画面には20行を表示します．横方向のスクロールは未対応です．

## mem — リアルタイム読み取り専用メモリビューア

`mem` または `mem 0x20018000` のように起動します．
既存の `/dev/mem` から約200ms間隔で読み取り，変化したバイトを反転表示します．
上下キーで8バイト，PgUp/PgDnで画面単位に移動します．SPACEで一時停止／再開，qで終了します．
読み取り可能な範囲は `/dev/mem` が許可するXIP Flash 0x10000000〜0x101fffff と SRAM 0x20000000〜0x2003ffff です．
内容は他タスクによって同時に変更されるため，一貫したスナップショットとは限りません．

`mem -s`でシンボル情報源の一覧を表示でき，`mem -s sh`や`mem -s kernel`でアプリ・カーネルのシンボル一覧を表示できます．通常のメモリ表示中も，現在のアドレスに対応するシンボルを表示します．

操作キー：`1`～`6`で各24 KiBタスクスロットへ，`k`でカーネルRAM，`K`でXIP Flashへ移動します．`g`で16進アドレスを入力してジャンプできます．シンボルデータが利用できなくてもメモリ表示は続行します．
