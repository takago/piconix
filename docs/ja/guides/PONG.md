# Pong

> **資料区分：操作ガイド（教科書本編ではありません）**．[対応する教科書の章](../learn/B/B2.md) ｜ [操作ガイド一覧](README.md)．

PicoNIXのPongは，1端末でCPUと遊ぶモードと，USB CDCの`/dev/console`と`/dev/ttyS1`を使用する2人対戦モードを備えています．どちらのTTYからでも起動できます．

## 起動方法

```text
piconix# pong       # 1人用（CPU対戦）
piconix# pong -2    # 2人用（2端末対戦）
```

**1人用**では起動元TTYだけを使用します．相手側のTTYがシェルなどで使用中でも実行できます．CPUは一定の間隔でボールの高さを追いかけます．難易度の設定はありません．

**2人用**では，もう一方のTTYを`OS_TTY_CLAIM`で一時取得します．相手側TTYをほかのプロセスが使用している場合は起動できません．各端末では自分のパドルが右側，相手が左側に表示されます．

ゲーム画面は起動元端末のサイズを調べて中央に配置します．2人対戦では両端末に同じ座標を使用するため，端末サイズが異なる場合は相手側では中央にならないことがあります．プレイ中の画面サイズ変更には対応しません．

## 操作

- **上矢印キー（↑）**：上へ移動
- **下矢印キー（↓）**：下へ移動
- `W`/`I`と`S`/`K`：従来どおり使用できる代替キー
- `Q`：終了

矢印キーはANSIエスケープシーケンス（`ESC [ A` / `ESC [ B`，または`ESC O A` / `ESC O B`）として処理します．2人対戦では各端末の入力を独立して判定します．

端末エミュレータの行入力モードをOFFにし，ANSIカーソル制御と代替画面を使用できるようにしてください．

## 端末設定と制約

Pongはゲーム中，使用するTTYを非canonical・エコーOFF・ノンブロッキング入力に切り替えます．通常終了時に設定を戻し，2人用では相手側TTYの取得を解除します．TTYの取得機能はPong専用ではなく，カーネルが管理する汎用機能です．

端末エミュレータの物理的な接続状態は検出しません．各ユーザプログラムには24 KiBのRAMスロットが割り当てられ，末尾4 KiBはスタック用に予約されます（プログラムイメージには最大20 KiBを使用できます）．ファームウェア全体のビルドと実機動作は別途確認が必要です．
