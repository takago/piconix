# fd — ファイルブラウザ

*操作ガイド*

`fd [directory]`はFDclone風の小型フルスクリーンファイルブラウザです．省略時は`/tmp`から開始します．上下矢印で選択し，Enterまたは右矢印でディレクトリやファイルを開きます．一覧先頭の`../`をEnterで開くか，Backspaceまたは左矢印で親ディレクトリへ戻り，`r`で一覧を再読み込み，`q`で終了します．

`/tmp`，`/etc`，`/proc`にあるファイルは，Enterで**約1秒ごとに再読み込みする読み取り専用ビューア**を開きます．変化する`/proc`の値を観察する用途にも使えます．表示はASCII文字を基本とし，制御文字などは`.`に置き換えます．ファイル全体を順次読み出せる行単位のビューアです．上下矢印で1行ずつ，PgUp/PgDnで1画面ずつ移動できます．2 KiBの画面バッファには現在の表示範囲だけを保持するため，`/proc/sym/kernel`などの大きなファイルも末尾まで閲覧できます．ただし，長い行は画面幅で切り詰めて表示します．ビューアからファイルは変更しません．`q`またはEscで一覧に戻ります．

ファイル選択中または閲覧中に`e`を押すと`edit`を起動します．編集できるのは`/tmp`または`/etc`直下のRAMファイルです．`edit`を終了すると`fd`に戻ります．編集前に入力の非ブロッキング設定を解除し，戻った後にブラウザの入力設定を復元します．

一覧は最大48件（親ディレクトリ`../`を含む），画面サイズは最大40行×110列に対応します．48件を超える項目は数だけ表示し，一覧には表示しません．コピー・削除・名前変更・移動は実装していません．`/dev`の読み取りは副作用やブロックの可能性があるため，ビューアから行いません．ANSIカーソルキーを扱える端末が必要です．

`../`は`fd`が独自生成するのではなく，VFSの`getdents()`から取得します．`.`はブラウザに表示せず，ルートでは`..`も表示しません．

`/proc/sym/kernel`では，カーネルが`lseek()`に対応していれば16行ごとのバイト位置を小さな索引として記録し，既知の位置へ直接移動します．ファイルを開き直す際にも索引を再利用します．別のファイルを開いたときや`r`を押したときは索引を初期化します．他の`/proc`ファイルは内容が変化し得るため，古い索引を使わず先頭から読み直します．`lseek()`非対応のカーネルでも従来の順次読み取りへ戻ります．索引は最大128項目で，対象範囲を超える行も閲覧できますが，読み飛ばしが必要になることがあります．
