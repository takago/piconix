# fd — ファイルブラウザ

*操作ガイド*

`fd` は，端末上でディレクトリを移動し，ファイルの内容を確認するための小型フルスクリーンブラウザです．FDclone風の操作ですが，Linuxのファイルマネージャと同じ機能がすべてあるわけではありません．

## 起動する

```sh
fd
fd /etc
fd /proc
```

`fd` だけなら `/tmp` から始まります．引数にディレクトリを指定すると，そこから閲覧します．**ANSIカーソルキーを扱える端末**で使用してください．

## 一覧での基本操作

| キー | 操作 |
|---|---|
| `↑` / `↓` | 項目を選択 |
| `Enter` / `→` | ディレクトリに入る，またはファイルを開く |
| `←` / `Backspace` | 親ディレクトリへ移動 |
| `../` を選んで `Enter` | 親ディレクトリへ移動 |
| `r` | 一覧を再読み込み |
| `e` | 選択中のファイルを `edit` で編集（編集可能なファイルのみ） |
| `q` | 終了 |

例えば `fd /proc` で一覧を開き，矢印キーで項目を選び，`Enter` で内容を確認します．戻るときは `q` または `Esc` です．**一覧画面の `q` は終了，ファイル閲覧画面の `q` は一覧への復帰**であり，動作が異なります．

## ファイルを閲覧する

`/tmp`，`/etc`，`/proc` のファイルでは，`Enter` で読み取り専用ビューアが開きます．表示内容は約1秒間隔で再読み込みされるため，値が変わる `/proc` ファイルの観察にも使えます．

| キー | ビューアでの操作 |
|---|---|
| `↑` / `↓` | 1行ずつスクロール |
| `PgUp` / `PgDn` | 1画面ずつスクロール |
| `e` | 編集可能なら `edit` を起動 |
| `q` / `Esc` | ファイル一覧へ戻る |

表示対象はテキストを想定し，制御文字などは `.` に置き換えます．長い行は端末の表示幅で切り詰めます．**ビューアはファイルを変更しません**．バイナリ内容を詳しく見る場合は `hexdump` を使ってください．

## 編集する

`/tmp` または `/etc` の直下にある編集可能なRAMファイルを選び，`e` を押すと `edit` が起動します．`edit` を通常どおり終了すると `fd` の一覧に戻ります．閲覧中に `e` を押す方法もあります．

`fd` は編集の前に標準入力の非ブロッキング設定を解除し，編集後にはブラウザ用の設定を復元します．ただし `/proc` は観察用であり，この操作で編集できません．詳しくは [editガイド](EDIT.md) を参照してください．

## 制限と内部動作

- 一覧表示は最大48件（親ディレクトリ `../` を含む）です．超過分の件数は表示されますが，項目自体は一覧に出ません．最大画面サイズは40行×110列です．
- コピー，削除，名前変更，移動はできません．必要なら対応するシェルコマンドを使います．
- `/dev` のデバイスノードは，読み取りに副作用や待機があり得るため，ビューアから開きません．
- `../` はVFSの `getdents()` から取得されます．`.` は非表示で，ルートでは `..` を表示しません．
- 2 KiBの表示用バッファには現在の範囲だけを保持します．そのため大きなファイルも順次閲覧できます．
- `/proc/sym/kernel` では，`lseek()` 対応時に16行ごとの位置を最大128件索引化して移動を高速化します．別ファイルを開くときや `r` を押したときは索引を破棄します．索引範囲外でも順次読み取りで閲覧可能です．他の `/proc` ファイルや `lseek()` 非対応環境では順次読み取りを使います．

**困ったとき：** キーが効かない場合はANSI対応の端末を使っているか確認してください．一覧に目的のファイルがない場合は，48件の表示上限と現在のディレクトリを確認し，必要なら `ls` も併用してください．
