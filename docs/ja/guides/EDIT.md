# edit — テキストエディタ

> **資料区分：操作ガイド（教科書本編ではありません）**．[対応する教科書の章](../learn/A/A2.md) ｜ [操作ガイド一覧](README.md)．

`edit`はRAMファイルのテキストを編集するプログラムです．メモリ領域を変更する機能ではありません．

`edit /tmp/test.s` で編集します．ファイルがなければ新規作成します．
矢印キーでカーソルを移動し，Enterで改行，TABは4桁単位で表示します（保存時はTABのまま）．
Ctrl+Sで保存，Ctrl+Qで終了します．未保存の変更がある場合は警告を表示し，もう一度Ctrl+Qを押すと保存せず終了します．
`edit`の編集バッファ上限は2,048バイト（RAMファイルと同じ），表示行数は端末の高さに応じて変わり（最大56行），長い行は横方向にスクロールします．


## 編集の手順

1. シェルから `edit /tmp/test.s` を実行します．既存のファイルを開くか，なければ新しいファイルを作成します．
2. 文字を入力し，矢印キーでカーソルを移動します．Backspaceで直前の文字を，Deleteでカーソル位置の文字を削除できます．
3. **Ctrl+S** で保存します．画面下部に `Saved` と表示されたことを確認します．
4. **Ctrl+Q** で終了します．保存していない変更が残る場合は警告を表示します．もう一度Ctrl+Qを押すと破棄して終了します．

例えば，`edit /tmp/hello.txt` で短いテキストを入力・保存した後，シェルで `cat /tmp/hello.txt` を実行すると，保存した内容を確認できます．Pico Wでは`edit /etc/index.html`で紹介ページを直接編集できます．変更内容は再起動すると失われます．

## 制限と注意

- 編集できるのは `/tmp` または `/etc` 直下のRAMファイルです．任意のメモリアドレスは編集できません．
- Ctrl+Cは**保存せずに終了**します．未保存の編集内容を失うため，通常はCtrl+Sで保存してからCtrl+Qで終了してください．
- ファイルが2,048バイトを超える場合は，切り詰めずにエラーで終了します．
- 保存に失敗した場合は `Save failed` と表示されます．ファイル容量や空き領域を確認してください．
- 端末の表示・入力モードを一時的に変更するため，ANSI制御に対応した端末を使用してください．
