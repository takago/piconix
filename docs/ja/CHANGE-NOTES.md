# プログラム登録数と端末表示の改善

- `kernel/kernel.c` のプログラム表は，予約ID 0に加え，ID 1～64を登録可能にした（同時実行タスク数は従来どおり）．今後アプリを増やす際は，`kernel/main.c` の登録と `CMakeLists.txt` のビルド対象への追加が別途必要．
- `edit` は起動時に端末へカーソル位置報告（`CSI 6n`）を要求し，端末の行・列数を判定する．応答しない端末は80×24で動作する．表示行数・横方向スクロールを調整し，1KiBの編集容量は変えない．
- `mem` は16バイト×16行（計256バイト）を表示し，16進とASCIIを並べる．先頭行に領域と状態を表示し，変化したバイトを反転表示する．`k` はカーネルSRAM，`1`～`5` はタスクスロット，`f` はXIP Flashの先頭へ移動する．矢印は16バイト，PageUp/PageDownは256バイト移動する．

**注意**：端末がカーソル位置報告に対応しなければ，`edit` の表示サイズは80×24になる．また，`mem` の `/dev/mem` アクセス範囲はカーネルによる制限を受ける．
