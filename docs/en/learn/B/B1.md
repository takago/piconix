## B1.1 What is an FD?

A file descriptor (FD) is a **number** referring to an I/O object opened by a process. Typically, 0 is standard input, 1 is standard output, and 2 is standard error. Code can use `read()` and `write()` without knowing the destination’s concrete type.

## B1.2 Observe FDs

```text
piconix# lsof
piconix# echo hello | cat
piconix# ps
```

`lsof` displays FD ownership at a moment in time. A short-lived command may already have exited when you inspect it. The [pipe guide](../../guides/PIPE.md) explains `pipe()`, `dup2()`, and EOF.

## B1.3 A common namespace with VFS

The VFS resolves paths and dispatches operations to their implementation. A regular file in `/tmp`, a device in `/dev`, and a live view under `/proc` do **not** share the same storage backend, even though processes use similar APIs to access them.

## B1.4 Practice and check
