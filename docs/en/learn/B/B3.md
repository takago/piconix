## B3.1 What stays in Flash?

PicoNIX runs kernel instructions from Flash with XIP. User application PIC images are stored in Flash, then copied into a selected **fixed RAM slot** when started. Distinguish *storage location* from *execution location*.

## B3.2 Inspect memory

```text
piconix# ps
piconix# mem -s
piconix# mem -s kernel
piconix# mem -s sh
```

Compare kernel and application symbols. Exact addresses and sizes vary by build. Do not modify memory while learning these concepts.

**Extra read-only observation:** Start `mem`; press `1`–`6` for user slots, `k` for kernel RAM, `K` for XIP Flash, and `q` to exit. Empty slots need not contain a program. Data can change while you are inspecting memory. Compare hexadecimal addresses with the [SRAM layout reference](../../reference/MEMORY-LAYOUT.md).

## B3.3 Why fixed slots?

RP2040 SRAM is limited. Fixed slots reduce implementation complexity, but impose limits on program size and concurrent tasks. PicoNIX does not implement Linux-style virtual memory.
