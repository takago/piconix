## C2.1 From main to sh

Read `kernel/main.c` and follow `os_init()` → `register_image()` → `net_init()` → `os_init_idle()` → `os_start_program(2)` → `os_start()`. Draw how **registration** differs from **starting** a task.

## C2.2 Prepare and switch tasks

Find `spawn_in_slot()`, `os_start_program()`, and `os_schedule()` in `kernel/kernel.c`, then follow SysTick and PendSV in `kernel/context.S`. Separate task selection from CPU context switching.

## C2.3 RAM slots and registers

Relate the fixed RAM slot, initial stack, saved registers, and PSP. Check constants in `include/piconix.h` and functions in the [function index](../../../FUNCTIONS.md), rather than memorizing addresses. PicoNIX does not duplicate Linux’s virtual memory model.

## C2.4 Reading assignment

Draw a 5–10 function flow diagram from boot to the first `sh`.

1. What differs between image registration and task launch?
2. How do SysTick and PendSV divide their work?
3. Why does the idle task exist?

Learning record: Write down **what you ran / what you observed / why it happened**.
