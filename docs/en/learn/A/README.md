# Part A — Beginner: Use UNIX

**Document type: TEXTBOOK CONTENTS** | [Course contents](../README.md) | [日本語](../../../ja/learn/A/README.md)

Begin with the shell, then work with files, pipes, and processes. A regular Pico is sufficient.

## Chapters

- [A1　Entering PicoNIX and UNIX](A1.md) — Start the shell and distinguish commands from operating-system responsibilities
- [A2　Files and streams](A2.md) — Understand the difference between saved data and flowing data
- [A3　Programs and processes](A3.md) — Distinguish available programs from running processes
- [A4　Beginner capstone: a small UNIX experiment](A4.md) — Bring the shell, files, streams, and processes together

**How to proceed:** Start at A1 and complete each chapter’s practice questions.

## Prerequisites and next Part

No prior OS knowledge is needed. Follow [Setup](../../setup/SETUP.md) for flashing and terminal access. Continue with [B1](../B/B1.md).
