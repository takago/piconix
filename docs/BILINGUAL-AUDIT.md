# PicoNIX 日英ドキュメント照合結果 / Bilingual documentation audit

対象：履歴分離後のリポジトリ．`docs/history/`の開発記録は対訳対象外としました．

## 実施した検査

- 現行ガイドの日英ファイル名の対応，見出し数，コードブロック数，本文量を比較しました．
- 相違の大きい文書の本文を読み，説明の欠落や現行ソースとの矛盾を確認しました．
- `kernel/net_service_remote_devctl.c`でUDPデバイス制御のパス許可，GPIO操作，要求サイズ，応答形式を照合しました．
- `kernel/kernel.c`でTTY設定保存・復元と`/proc/sym/kernel`を確認しました．
- ローカルMarkdownリンクの参照先存在を確認しました．

## 修正内容

- 日本語に欠けていた`HTTPD.md`と`REMOTE_GPIO.md`を追加．英語に欠けていた`RESET.md`を追加．
- 英語版カーネルシンボル説明の古い`/proc/syms`参照を現行の`/proc/sym/kernel`等に更新．
- UDPデバイス制御にGPIO操作を追記し，APとSTA双方の接続先を説明．
- `NETWORK.md`の切断方法と説明見出しを整理．
- TTYの前景タスク終了時の設定復元を日本語にも独立して記載．
- READMEの英語版末尾に残った独立したWi-Fi節を文書案内へ統合．
- `DOCS.md`の日英リンクと文書案内を更新．

## 残る確認事項

本監査は文章構造と主要な意味の不一致を修正したものです．全行の逐語翻訳一致，すべてのサンプルの実機実行，すべてのシステムコールの境界条件の動作確認を保証しません．日英は直訳ではなく，技術情報の等価性を目標としています．
