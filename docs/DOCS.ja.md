# PicoNIX ドキュメント案内

PicoNIXの文書は，目的に応じて**操作ガイド・技術リファレンス・開発ガイド**に分けています．学習順序を知りたい場合は[学習ロードマップ](ja/ROADMAP.md)を参照してください．

## はじめに：セットアップ

**[セットアップ手順](ja/setup/SETUP.md)**：Pico／Pico Wへの書き込みと，Linux PCからのUSB端末接続を準備します．

## 1．順番に学ぶ（学習ロードマップ）

**[学習ロードマップ](ja/ROADMAP.md)**：操作からOSの観察，プログラムとカーネルの改造まで，実習資料を読む推奨順序を案内します．

## 2．やりたいことから探す（目的別索引）

**[目的別索引：何をしたい？ → 関連ページ一覧](ja/TASKS.md)**

特定の目的が決まっている場合は，「ファイルを編集したい」「`trace`で確認したい」「ドライバを追加したい」など，**目的から操作ガイド・実習・リファレンスを横断して探せます**．

## 3．個別のコマンドを調べる（操作ガイド）

**[操作ガイド一覧](ja/guides/README.md)**：`help`，パイプの詳細，端末設定，`trace`，`mem`，エディタなど，コマンド固有の使い方を調べられます．必要な操作をその場で試せるように解説しています．

## 4．現行仕様を調べる（技術リファレンス）

**[技術リファレンス目次](ja/reference/README.md)**：システムコール，FD，メモリ配置，デバイスノード，ネットワーク仕様，制限値など．学習順序を持たない辞書として使用します．

分野別： [ハードウェア・ピン割当・配線](ja/reference/hardware/README.md) ｜ [デバイスとI/O](ja/reference/devices/README.md) ｜ [ネットワーク（Pico W）](ja/reference/network/README.md)．

## 5．開発方法を調べる（開発ガイド）

**[開発ガイド一覧](ja/development/README.md)**：C・Python・アセンブラ，カーネル読解，システムコール，ドライバ追加，Pico Wネットワークの実装など．最初に[学習ロードマップ](ja/ROADMAP.md)で順序を確認してください．

## 関数索引と開発記録

- [関数一覧（自動生成）](FUNCTIONS.md)：ソースコードを調べるときの索引．
- [開発日誌](DEVELOPMENT_DIARY.ja.md)：設計の経緯．
- [過去の検討・履歴](history/README.md)：現行仕様と異なる情報も含むため，APIや制約の確認には使わないでください．
