# PicoNIX ドキュメント案内

PicoNIXの文書は，目的に応じて**教科書・操作ガイド・技術リファレンス・開発ガイド**に分けています．教科書ではA1.1のような章節番号を使います．

## はじめに：セットアップ

**[セットアップ手順](ja/setup/SETUP.md)**：Pico／Pico Wへの書き込みと，Linux PCからのUSB端末接続を準備します．

## 1．UNIXを順番に学ぶ（教科書）

**[教科書総目次：Part A・B・C](ja/learn/README.md)**

| パート | 学習ストーリー | 最初の章 |
|---|---|---|
| **Part A（初級）** | シェル → ファイルとパイプ → プロセス | [A1 PicoNIXとUNIXの入口](ja/learn/A/A1.md) |
| **Part B（中級）** | FD/VFS → TTY → メモリ → SVC観察 → デバイス → ネットワーク（選択） | [B1 FDとVFS](ja/learn/B/B1.md) |
| **Part C（上級）** | ユーザC → 起動とスケジューラ → SVC/VFS → ドライバ → ネットワーク（選択） → 改造 | [C1 ユーザプログラム](ja/learn/C/C1.md) |

教科書の章節には`A1.1`などの番号があり，ページ末尾に**前へ・Part目次へ・次へ**を置いています．Pico W専用の章は選択です．

## 2．やりたいことから探す（目的別索引）

**[目的別索引：何をしたい？ → 関連ページ一覧](ja/TASKS.md)**

教科書を順番に読む必要がない場合は，「ファイルを編集したい」「`trace`で確認したい」「ドライバを追加したい」など，**目的から教科書・実習・リファレンスを横断して探せます**．この索引は教科書の章ではありません．

## 3．個別のコマンドを調べる（操作ガイド）

**[操作ガイド一覧](ja/guides/README.md)**：`help`，パイプの詳細，端末設定，`trace`，`mem`，エディタなど，コマンド固有の使い方を調べられます．段階的な基礎実習は教科書に統合済みです．**教科書のナビゲーションは付けません**．

## 4．現行仕様を調べる（技術リファレンス）

**[技術リファレンス目次](ja/reference/README.md)**：システムコール，FD，メモリ配置，デバイスノード，ネットワーク仕様，制限値など．学習順序を持たない辞書として使用します．

分野別： [ハードウェア・ピン割当・配線](ja/reference/hardware/README.md) ｜ [デバイスとI/O](ja/reference/devices/README.md) ｜ [ネットワーク（Pico W）](ja/reference/network/README.md)．

## 5．開発方法を調べる（開発ガイド）

**[開発ガイド一覧](ja/development/README.md)**：C・Python・アセンブラ，カーネル読解，システムコール，ドライバ追加，Pico Wネットワークの実装など．最初に[Part C](ja/learn/C/README.md)で順序を確認してください．
